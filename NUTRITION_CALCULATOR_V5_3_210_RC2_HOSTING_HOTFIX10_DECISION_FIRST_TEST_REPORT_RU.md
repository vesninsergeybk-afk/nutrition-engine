# HOTFIX10 DECISION FIRST — отчёт о тестировании

## Итог

Проверен новый сценарий раздела «Улучшить», навигационная оболочка, профильный маршрут и основные неизменённые расчётные контуры. Критических дефектов в проверенном Chromium-контуре не обнаружено.

- профиль и потребности: 12 из 12;

Все перечисленные проверки завершились успешно.

## Специализированные браузерные сценарии HOTFIX10

Отдельно пройдены четыре сценария Chromium:

1. готовый вариант рассчитывается автоматически, не меняет основной рацион до подтверждения, применяется и отменяется;
2. ручная граммовка остаётся вторичным режимом и пересчитывается автоматически;
3. на ширинах 390 и 1440 пикселей отсутствуют серьёзные и критические нарушения axe, горизонтальное переполнение не обнаружено;
4. ИИ-помощник явно отделён и открывается только через дополнительный путь.

## Регрессионные браузерные проверки

- навигационная оболочка: 5 из 5;
- app smoke: 5 из 5;
- общий release gate: 4 из 4;
- профессиональный рабочий процесс: 2 из 2;
- профиль и потребности: 4 из 4;
- формульные golden-сценарии: 3 из 3;
- HEI HF3: 1 из 1.

Часть длительных локальных серий Playwright в управляемом Chromium иногда не завершала сам процесс после уже выведенного успешного результата тестов. Поэтому в итоговый перечень включены только сценарии, для которых получен явный результат прохождения; зависание процесса не засчитывалось как дополнительное подтверждение.

## Проверенные свойства сценария

- не более трёх направлений на первом уровне;
- два готовых количественных варианта;
- сравнение доступных вкладчиков по рассчитанным побочным эффектам;
- отсутствие мутации рациона в режиме предпросмотра;
- полный канонический пересчёт нутриентов и HEI;
- блокировка применения, если целевой показатель не улучшается;
- явное подтверждение изменения;
- отмена последнего изменения;
- защита отмены от перезаписи последующей ручной правки;
- ручной режим скрыт по умолчанию;
- подробные изменения скрыты по умолчанию;
- ИИ не смешивается с расчётным правилом;
- корректный клавиатурный переход skip-link к полям профиля;
- одна нижняя навигационная панель на телефоне.

## Ограничения проверки

- локально полноценно проверен Chromium;
- Firefox и WebKit требуют отдельного CI-прогона;
- TalkBack и VoiceOver требуют ручной проверки на физических устройствах;
- автоматический axe-аудит не заменяет полноценную проверку вспомогательными технологиями;
- сценарии замены и добавления продуктов в этот релиз не входят.
