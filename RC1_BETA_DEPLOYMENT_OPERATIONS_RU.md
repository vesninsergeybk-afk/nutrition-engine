# RC1 — инструкция по развёртыванию и диагностике

## 1. Публикация

1. Создайте на сервере новый чистый каталог релиза.
2. Распакуйте в него `nutrition_calculator_v5_3_210_RC1_HOSTING_PRIVATE_AUDITED.zip`.
3. Не копируйте RC1 поверх PC2: старые файлы не должны оставаться в каталоге.
4. Проверьте права: каталоги обычно `755`, файлы `644`.
5. Убедитесь, что `api/gemini-secret.php` недоступен по HTTP и содержит серверный ключ только на сервере.
6. Переключите document root или симлинк на новый каталог атомарно.

## 2. Первичная ручная проверка

Откройте главную страницу в режиме инкогнито и выполните:

- расчёт потребностей;
- поиск и добавление одного продукта;
- подтверждение полного дня после заполнения тестового рациона;
- переключение двух вкладок результата;
- открытие блока «Beta-диагностика и обратная связь»;
- кнопку «Проверить работу».

Ожидаемо: нет `FAIL`; предупреждение о HTTP допустимо только на временном локальном стенде. На публичном сервере должен использоваться HTTPS.

## 3. Автоматический remote smoke

Из полного архива:

```bash
python3 tools/remote_smoke.py https://example.org/path-to-calculator
```

Тест проверяет:

- health API и версию RC1;
- защитные заголовки;
- запрет индексации;
- `robots.txt`;
- beta support asset;
- immutable cache;
- закрытие secret, tests, tools и hosting-check;
- обязательность CSRF.

## 4. Сообщение об ошибке

Попросите тестировщика:

1. открыть beta-диагностику;
2. нажать «Проверить работу»;
3. скачать диагностический JSON;
4. приложить его к описанию действий, ожидаемого и фактического результата;
5. приложить снимок экрана только после удаления персональных данных.

Диагностический JSON не заменяет скриншот или точное описание сценария.

## 5. Откат

Храните PC2 и RC1 в разных каталогах. Для отката переключите document root/симлинк обратно на каталог PC2. Не смешивайте файлы двух версий.

## 6. Что не публиковать

Не загружайте на публичный сервер FULL-архив, каталог `validation/`, `tests/`, `tools/`, `config/`, отчёты и приватный reference answer key. Для сервера предназначен только HOSTING ZIP.
