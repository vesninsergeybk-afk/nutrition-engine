# V6 Beta 7 — восстановление навигации и режимов

Версия: **`v6.0.0-beta7-navigation-recovery`**  
Основание: **V6 Beta 6 Design Refinement**.

Beta 7 исправляет функциональные регрессии, обнаруженные при ручной проверке готовой мобильной версии: исчезновение доступного переключателя тем, отключённый режим «Полотно» и потерю постоянного доступа к профилю и расчёту потребностей после перехода к рациону. Расчётное ядро, нормы, продуктовая база и аналитические методы не изменялись.

## Развёртывание

1. Сделайте резервную копию текущей серверной папки.
2. Распакуйте **hosting private** в корень приложения с заменой файлов.
3. Убедитесь, что `api/gemini-secret.php` имеет права `0600` и недоступен напрямую по HTTP.
4. Откройте приложение с очисткой cache или с новым параметром версии.
5. Проверьте:
   - видимость трёх тем;
   - переключение «Разделы / Полотно»;
   - постоянную кнопку «Потребности»;
   - возврат к профилю после расчёта;
   - печать/PDF;
   - поиск, сводную таблицу, HEI и Gemini.

Для аварийного запуска стандартного оформления доступен `?safe-ui=1`.

Приватный архив содержит серверные ключи Gemini и не должен размещаться в публичном каталоге загрузок.
