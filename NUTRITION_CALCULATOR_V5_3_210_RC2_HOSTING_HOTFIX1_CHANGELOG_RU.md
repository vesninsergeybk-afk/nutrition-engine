# RC2 Hosting Hotfix 1 — журнал изменений

Исправлена ложная блокировка запуска на медленном или ограниченном shared-хостинге без изменения формул, нормативов, продуктовых значений и профессионального интерфейса RC2.

## Изменения

- 35-секундный browser watchdog больше не объявляет работающий bootstrap несовместимой средой.
- Автоматическое аварийное окно появляется только если стартовый bootstrap не был загружен либо bootstrap сообщил фактическую фатальную ошибку.
- 12 частей продуктовой базы загружаются ограниченной очередью из четырёх параллельных запросов вместо последовательной загрузки.
- Дополнительные runtime-модули загружаются ограниченной очередью из шести запросов; таймер каждого файла начинается только после его фактической постановки на загрузку.
- Сетевые тайм-ауты увеличены для shared-хостинга и медленного мобильного соединения.
- При реальной ошибке в технические сведения передаётся фактическая причина и список не загрузившихся runtime-файлов.
- Тексты ошибки больше не предлагают обновлять современный браузер при обычной сетевой или серверной проблеме.
- Query cache keys стартовых файлов обновлены до `rc2-hf1`, чтобы браузер не использовал старый bootstrap после публикации.

## Не изменялось

- продуктовая база и её числовые значения;
- HEI и зарегистрированные формулы;
- нормативный реестр;
- protected modes;
- восстановленный профессиональный рабочий поток RC2;
- API-протокол и Gemini guard.
