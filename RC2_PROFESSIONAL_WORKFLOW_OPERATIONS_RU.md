# Эксплуатация RC2

## Публикация
Распаковать HOSTING ZIP в новый чистый каталог. Не смешивать файлы RC1 и RC2.

## Ожидаемый runtime
- `config/runtime-assets.v5.3.210-rc2.json` — канонический список;
- `assets/runtime/runtime-manifest-v5.3.210-rc2.js` — браузерный манифест;
- `assets/css/runtime-bundle-v5.3.210-rc2.css` — единый CSS bundle;
- `assets/js/67-professional-workflow-restoration-v5.3.210-rc2.js` — профессиональный рабочий поток;
- `assets/js/69-release-support-v5.3.210-rc2.js` — закрытая диагностическая поддержка.

## Быстрая проверка после загрузки
1. Рассчитать потребности.
2. Добавить продукт.
3. Убедиться, что HEI, итоги и матрица видны без отдельного подтверждения дня.
4. Раскрыть Гарвардскую тарелку.
5. Проверить поиск базовых продуктов.
6. Открыть диагностику в нижней части страницы при необходимости.

## Откат
Сохранить RC1 в отдельном каталоге и переключать каталог целиком, а не отдельные файлы.
