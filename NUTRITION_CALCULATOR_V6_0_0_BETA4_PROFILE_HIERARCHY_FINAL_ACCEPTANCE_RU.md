# Итоговая приёмка V6 Beta 4 Profile Hierarchy

HOTFIX30 считается выполненным при одновременном соблюдении следующих условий:

- пользователь сразу видит пять основных полей;
- необязательные и специальные параметры не мешают первому шагу;
- ни одно профессиональное поле не удалено;
- рассчитанный профиль и черновик корректно переживают перезагрузку;
- основная кнопка не выполняет лишний повторный расчёт актуального профиля;
- полная сводная таблица, HEI, интегральный профиль, Гарвардская тарелка и единый отчёт работают;
- все три темы и обе desktop-компоновки сохранены;
- мобильная модель остаётся последовательной;
- Gemini не потерял фото-, голосовой и файловый ввод;
- формулы, нормы и продуктовые данные не изменились;
- готовый hosting-архив повторно проверяется после чистой распаковки.

Автоматизированная часть приёмки подтверждает эти условия. Внешними остаются живой хостинг, реальные мобильные разрешения, Safari/Samsung Internet/Qt WebEngine и пользовательское наблюдение.
