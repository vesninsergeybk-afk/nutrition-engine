# Развёртывание V6 Beta 3

1. Сделайте резервную копию текущего сайта.
2. Загрузите hosting-private ZIP в закрытое или временное место.
3. Распакуйте содержимое в корень приложения с заменой файлов.
4. Проверьте, что `api/gemini-secret.php` имеет права `0600` и не выдаётся прямым HTTP-запросом.
5. Удалите загруженный ZIP из публичного каталога.
6. Откройте сайт с параметром `?safe-ui=1`; должна загрузиться Modern.
7. Проверьте три темы, профиль, добавление продукта, полную таблицу, HEI, Гарвардскую тарелку, голос и фотографию.
8. Затем откройте обычный адрес и выберите Ivory & Brass.

Существующие основной и резервный ключи Gemini уже включены только в защищённый серверный файл. Они не должны появляться в HTML, JavaScript, ответах API или журналах.

При проблеме с новым UI используйте `?safe-ui=1`: данные профиля и рациона при этом не удаляются.
