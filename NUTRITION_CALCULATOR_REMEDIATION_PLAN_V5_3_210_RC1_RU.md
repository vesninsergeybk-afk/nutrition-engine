# План предрелизного прохода RC1

**Версия поставки:** `v5.3.210-rc1`  
**Продуктовая основа:** `v5.3.210-pc2`  
**Дата фиксации:** 19 июля 2026 года

## Назначение прохода

RC1 не является новым продуктовым редизайном и не меняет нормативы, формулы или числовые значения продуктовой базы. Его задача — подготовить PC2 к реальному размещению на сервере и последующему наблюдаемому beta-тестированию.

Проход закрывает четыре практические задачи:

1. сделать серверную сборку самодиагностируемой;
2. не допустить индексирования тестовой версии поисковыми системами;
3. обеспечить корректное кэширование версионированных ресурсов и отсутствие кэширования HTML/API;
4. дать воспроизводимый способ проверить сервер после загрузки и передать техническую сводку без содержимого рациона.

## Scope RC1

### Входит

- privacy-safe диагностический модуль в интерфейсе;
- проверка runtime, продуктовых чанков, UX-контракта, статуса внешней валидации и API;
- экспорт диагностического JSON и краткой текстовой сводки;
- `robots.txt` и заголовок `X-Robots-Tag: noindex, nofollow, noarchive`;
- immutable-кэш для `/assets/` и `/data/`, включая размещение в подпапке сайта;
- no-cache для HTML и no-store для API;
- дополнительные защитные HTTP-заголовки;
- gzip/deflate для текстовых ресурсов;
- удалённый smoke-тест `tools/remote_smoke.py`;
- включение Product Validation Sprint в полный архив;
- отдельные modern и legacy реализации диагностического слоя;
- автоматические unit, Apache и Chromium-проверки.

### Не входит

- изменение формул потребностей, HEI или продуктовой арифметики;
- замена нормативных источников;
- правка значений в 1105 продуктовых карточках;
- объявление продукта клинически валидированным;
- сбор телеметрии или отправка данных на внешний сервер;
- пользовательские исследования, которые будут выполнены после публикации.

## Критерии готовности

RC1 готов к размещению, если:

- runtime генерируется детерминированно;
- HOSTING содержит только точный runtime closure, manifest и SBOM;
- диагностический файл не содержит имя, состав и граммы рациона, заметки, запросы ИИ, загруженные материалы, cookies, CSRF и содержимое storage;
- Apache подтверждает защитные заголовки, noindex, immutable-кэш и сжатие;
- Chromium подтверждает основной PC2-поток и работу beta-диагностики;
- FULL содержит исходники, документацию, тесты, реестры и Product Validation Sprint;
- внешний статус остаётся `EXTERNAL_VALIDATION_PENDING`.

## Решение после RC1

RC1 становится единственной версией, которую следует загрузить на сервер для дальнейших тестов. Следующие изменения продукта допускаются только по результатам:

- реальных server smoke-проверок;
- наблюдаемых пользовательских сеансов;
- содержательной ревизии Priority-100;
- подтверждённых дефектов, а не по формальному продолжению нумерации проходов.
