# Аудит региональной анатомии и виртуальных препаратов

Дата контрольной точки: 2026-09-25.

## Контуры проверки

### 1. Анатомическая семантика препаратов и глубины

Проверено:
- учебные цели отделены от анатомического контекста сцены;
- 29 виртуальных препаратов не пусты ни в Z-Anatomy, ни в BodyParts3D;
- общие мышечные концепты не меняют принадлежность к препарату между источниками;
- для компактных комплексов зафиксирована ожидаемая мощность набора: ротаторная манжета 4, hamstrings 3, quadriceps 4, икроножно-камбаловидный комплекс 3 и др.;
- «Глубже здесь» использует только проверенный depth profile и явный граф отношений покрытия, а не один лишь следующий ray hit;
- сторона мышцы учитывается, поэтому правый и левый пути глубины не смешиваются.

Исправлено:
- повторный клик по уже изолированной мышце больше не рассинхронизирует состояние сцены и кнопку «Показать окружение»;
- смена модели и смена препарата очищают старые deeper-links;
- мышца следующего ранга больше не считается автоматически лежащей «глубже здесь» без подтверждённого отношения covers → deeper.

Ограничение:
- карты глубины пока подтверждены не для всей библиотеки. Проверенные профили покрывают плечевой пояс, брюшную стенку на полном источнике и часть препаратов спины.
- шейно-воротниковая зона, ягодичная область, бедро, голень, предплечье/кисть, стопа и ряд других препаратов остаются depth=unverified до отдельного анатомического прохода.

### 2. Пространственная изоляция

Проверено:
- каждый виртуальный препарат имеет spatial window;
- BodyParts3D bounds не показывают полного вырезания ни одной учебной цели;
- clipping применяется не только к рендеру, но также к ray hits, framing камеры и доступу к целевой мышце;
- покровные/context muscles не расширяют framing за пределы учебного препарата;
- региональный поиск не пересобирает список структур для каждого mesh.

Ограничение:
- BodyParts3D содержит только 1 из 5 целевых мышц полной брюшной стенки. Источник помечается source-incomplete, анатомическая послойность живота в нём отключена; Z-Anatomy содержит 5/5.

### 3. Переходы состояния

Проверены и защищены:
- выбор мышцы → deeper-links → изоляция → возврат окружения;
- смена препарата;
- смена источника модели;
- ручное скрытие и возврат;
- переход Атлас ↔ Тренировка;
- восстановление тканевых и костных настроек после изоляции/тренировки.

### 4. Межисточниковая согласованность и русский интерфейс

Проверено:
- общая семантика препаратов между Z-Anatomy и BodyParts3D;
- стабильные идентификаторы общих мышечных концептов;
- все мышечные mesh Z-Anatomy имеют русские пользовательские названия;
- все 416 мышечных mesh BodyParts3D теперь отдельно проверяются на русские Atlas-названия без латинских фрагментов;
- немышечные структуры вроде linea alba не попадают в список «Глубже здесь».

### 5. Костные ориентиры, регрессии и производительность

Проверено:
- у каждого препарата есть именованные костные ориентиры в обоих источниках;
- для плечевого пояса и ротаторной манжеты отдельно защищено наличие лопатки, ключицы и плечевой кости;
- костный слой остаётся отдельным, регионально фильтруемым support-layer;
- исключены O(N²)-style проверки региональной принадлежности;
- смена препарата не выполняет двойную полную перестройку сцены;
- браузерный checkpoint разделён на ограниченные фазы вместо одного монолитного прогона.

## Архитектурный долг, обнаруженный аудитом

В селекторе есть семантически дублирующиеся входы:
- «Бедро — задняя поверхность» и «Мышцы задней поверхности бедра»;
- «Бедро — медиальная группа» и «Приводящая группа бедра»;
- «Переднебоковая брюшная стенка» как топографический и тематический препарат.

Их не следует удалять без учёта deep links, но в UI лучше представить вторые названия как алиасы/быстрые входы к одному каноническому препарату, а не как независимые сущности.

## Следующий содержательный этап

После зелёного browser checkpoint:
1. расширить проверенные depth profiles на шейно-воротниковую, ягодичную, бедро и заднюю группу голени;
2. затем на предплечье/кисть и стопу с их компартментной логикой;
3. после этого переходить к Motion Lab (локоть → плечевой комплекс).
