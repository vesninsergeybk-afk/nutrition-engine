# Сравнение координатных 3D-моделей

## Вывод на текущем этапе

Одной модели, которая одновременно доказанно выигрывает по анатомической корректности, геометрической детализации, полноте структур, лицензии и скорости в браузере, пока не найдено.

Поэтому на этапе разработки применяется **модельное сравнение**, а не преждевременный выбор одного «победителя».

## Z-Anatomy — исходный Blender atlas

Роль: кандидат на детальную геометрию, совместимую с текущим прототипом.

Факты:
- открытый исходный архив `Z-Anatomy.zip` в официальном репозитории имеет размер около 86,7 МБ;
- текущий web-экспорт мышечной системы `kas.glb` — около 8,1 МБ;
- автор web-конверсии указывает, что мышечная система при экспорте была уменьшена примерно до 18% оценённого числа треугольников.

Преимущество для нас: можно экспортировать **только плечевой регион** из исходного Blender-атласа без глобального decimate и сохранить координатную совместимость с текущей Z-Anatomy моделью.

Ограничение: увеличение числа полигонов не устраняет возможные анатомические ошибки исходного атласа.

Статус: `candidate_hq_same_coordinate_system`.

## Z-Anatomy web GLB

Роль: текущий интерактивный прототип.

Плюсы:
- уже работает в браузере;
- структуры кликабельны;
- единая координатная модель;
- малый относительно исходника размер.

Минусы:
- существенная decimation;
- не прошёл нашу поструктурную анатомическую валидацию;
- CC BY-SA усложняет закрытый коммерческий сценарий.

Статус: `current_interaction_prototype`.

## BodyParts3D 4.0 / Human Atlas conversion

Роль: независимая контрольная координатная система и проверка структуры данных.

Плюсы:
- официальный BodyParts3D 4.0;
- единый целостный человек;
- богатая FMA/concept-структура;
- официальная база DBCLS сейчас CC BY 4.0.

Минусы:
- официальный downloadable mesh опубликован с polygon reduction rate 99%;
- Human Atlas дополнительно оптимизирует mesh для браузера;
- не является источником максимальной поверхностной детализации;
- сами авторы BodyParts3D предупреждают о возможных ошибках для образовательного использования.

Статус: `candidate_reference_geometry`.

## BodyParts3D / Anatomography 4.3 full-resolution candidate

Роль: кандидат на максимально подробную геометрию и детальную сегментацию мышц.

Сильная сторона для функциональной анатомии:
- отдельные части deltoid, trapezius и pectoralis major;
- отдельные головки biceps/triceps;
- отдельные мышцы rotator cuff и другие мышцы плечевого комплекса.

Проблемы:
- найденный pipeline получает данные через недокументированные Anatomography endpoints;
- происхождение и применимая лицензия конкретного downloadable набора требуют отдельного подтверждения;
- сторонний manifest нельзя слепо использовать как терминологический источник;
- полного отдельного набора капсулы/лабрума/основных плечевых связок и сухожилий в проверенном manifest не обнаружено.

Статус: `candidate_high_detail_pending_provenance_and_license_review`.

## AnatomyTOOL / Open3DModel

Роль: независимая региональная экспертная сверка.

Сильная сторона:
- материалы создаются и собираются в академической анатомической среде;
- есть отдельные региональные модели, включая rotator cuff;
- особенно полезно для проверки пространственных отношений и учебной адекватности.

Ограничение:
- это не одна универсальная координатная whole-body модель;
- лицензия проверяется для каждого отдельного материала.

Статус: `regional_validation_source`.

## Что сравниваем в интерфейсе сейчас

В опубликованном тесте доступен переключатель:

1. **Z-Anatomy web** — текущая рабочая модель.
2. **BodyParts3D 4.0 (контроль)** — независимая контрольная модель плечевого региона.
3. **BodyParts3D 4.3 full-res** отображается как кандидат, но не загружается в публичный интерфейс до разрешения вопроса происхождения и лицензии.

Следующий наиболее полезный кандидат для переключателя — shoulder-only экспорт исходной Z-Anatomy без сильного decimate. Он позволит отделить вопрос «качество исходной геометрии» от вопроса «потери при web-оптимизации».


## Дополнительные кандидаты для честного сравнения

### BodyParts3D 3.0 — 95% reduction

Это официальный исторический набор DBCLS. Архив `BodyParts3D_3.0_obj_95.zip` имеет размер около 521–522 МБ. Документация DBCLS прямо указывает, что вариант 95% содержит примерно в пять раз больше полигонов, чем 99%-вариант.

Роль: контроль того, насколько потеря геометрии при агрессивном polygon reduction влияет на узнаваемость мышц и костных ориентиров.

Ограничение: версия 3.0 существенно старше 4.0, поэтому большее число полигонов не делает её автоматически анатомически предпочтительной.

Статус: `official_high_polygon_historical_reference`.

### Visible Human / NIH 3D — мышцы верхней конечности

NIH 3D публикует модели мышц правой и левой руки, созданные из Visible Human Male Cryo + CT; сегментация выполнена в 3D Slicer, затем модели оптимизированы и remesh-нуты.

Роль: независимый imaging-derived контроль реальных пространственных отношений в плечевом/верхнеконечностном регионе.

Ограничение: это региональная модель конкретного тела, а не универсальный whole-body учебный атлас.

Статус: `imaging_derived_regional_reference`.

### Human Reference Atlas 3D Reference Object Library

NIH 3D публикует экспертно-рецензируемую HRA коллекцию reference organs: модели создаются медицинскими 3D-иллюстраторами и утверждаются экспертами по органам.

Роль: высокий стандарт происхождения и экспертного контроля, полезный как benchmark качества.

Ограничение для нашего проекта: коллекция не является полноценным детальным whole-body мышечным атласом плечевого пояса, поэтому не заменяет Z-Anatomy/BodyParts3D как базовую мышечную координатную модель.

Статус: `expert_review_benchmark_not_primary_muscle_atlas`.

## Приоритет экспериментов

1. Z-Anatomy shoulder-only export без сильного decimate — наиболее чистый способ проверить, насколько текущая потеря качества вызвана именно web-оптимизацией при сохранении тех же координат.
2. BodyParts3D/Anatomography 4.3 full-resolution — проверить геометрическую детализацию и сегментацию, но не публиковать до разрешения provenance/license.
3. BodyParts3D 3.0 95% — официальный высокополигональный исторический контроль.
4. AnatomyTOOL/Open3DModel rotator cuff — экспертная региональная проверка формы и отношений.
5. Visible Human / NIH 3D arm muscles — независимый imaging-derived контроль.

Ни один источник не объявляется «лучшим» заранее. Сравнение должно выполняться на одинаковом наборе структур плечевого комплекса и по одинаковым критериям: форма, места начала/прикрепления, отношение к костям, детализация границ, разделение частей мышцы, топологические дефекты, производительность и пригодность для выбора на мобильном устройстве.


## Новые результаты внешней проверки

### Human Reference Atlas (NIH/HuBMAP): сильный benchmark, но не основной атлас мышц плеча

HRA действительно заслуживает высокого доверия к процессу происхождения: NIH 3D описывает коллекцию как expert-reviewed 3D reference organs; модели создаются специалистами по медицинской 3D-иллюстрации и утверждаются экспертами по соответствующим органам.

Но для нашей конкретной задачи есть важное ограничение: HRA whole-body reference set — это прежде всего сборка reference organs. В доступных описаниях HRA/производных viewer-проектов покрытие скелета и мышц указано как частичное; отдельной полной модели мышц плечевого пояса HRA сейчас не предоставляет. Поэтому HRA полезен как **эталон качества процесса, provenance и экспертного review**, но не как непосредственная замена нашей мышечной координатной модели.

Статус: `expert_review_benchmark_not_primary_shoulder_muscle_atlas`.

### Humanum / BodyParts3D 3.0 95%: очень сильный аргумент в пользу отдельного HQ-теста

Humanum — независимый исследовательский viewer, который использует BodyParts3D release 3.0 95% без remeshing исходных OBJ перед последующей point-sampling визуализацией. Его собственный аудит сообщает:

- 437 мышечных mesh;
- 18,308,056 треугольников в мышечной системе;
- отдельные головки biceps и части trapezius;
- scapula как один из наиболее детализированных костных объектов — 121,816 треугольников;
- все базовые системы BodyParts3D 3.0 остаются в одной координатной системе TARO.

Humanum отдельно утверждает, что для своей задачи предпочёл 3.0, потому что в 4.0 после repositioning встречаются пересечения skin/muscle, тогда как 3.0 лучше сохраняет взаимное совпадение систем. Это вывод стороннего проекта, а не официальный verdict DBCLS, поэтому мы используем его как **сильную гипотезу для проверки**, а не как окончательный факт.

Статус: `high_priority_hq_coordinate_candidate`.

### Open3DModel / AnatomyTOOL: сильнее, чем мы первоначально учитывали

Open3DModel доступен не только как отдельная картинка rotator cuff. LUMC поддерживает web-viewer с отдельными upper-limb/shoulder моделями, где структуры можно включать/выключать по одной или группами, выбирать кликом и скрывать. Независимый проект InjuryAtlas уже использует Open3DModel/AnatomyTOOL именно как detailed shoulder model, а также как источник плечевых ligaments/nerves.

Практический вывод: Open3DModel стоит рассматривать не только как reference для визуальной проверки, но и как кандидат на **региональную плечевую геометрию**, особенно для глубоких мышц, связок и нервов.

Статус: `regional_geometry_candidate_and_validation_source`.

### Visible Human Male arm muscles (NIH 3D)

NIH 3D содержит отдельные right/left arm muscle модели из Visible Human Male Cryo + CT. На странице NIH указано, что мышцы и кости были сегментированы в 3D Slicer, затем модели оптимизированы и remesh-нуты в ZBrush.

Это делает их хорошим независимым imaging-derived reference для плеча и верхней конечности. Они не должны автоматически становиться основной координатной моделью, потому что представляют конкретное тело и уже прошли remesh, но очень полезны для проверки взаимного положения мышц и костей.

Статус: `imaging_derived_regional_reference`.

## Обновлённый приоритет shoulder benchmark

Для следующего сравнения плеча приоритет теперь такой:

1. **BodyParts3D 3.0 95% / HQ shoulder subset** — сохранить исходную TARO-координатную систему и максимальную доступную официальную плотность этой линии.
2. **Open3DModel upper limb / shoulder** — академическая региональная модель с глубокими структурами, ligaments/nerves и готовой практикой web-viewer.
3. **Z-Anatomy source shoulder export без сильного decimate** — проверить вклад анатомических правок Z-Anatomy и потери текущей web-конверсии.
4. **Visible Human Male arm muscles (NIH 3D)** — imaging-derived контроль.
5. **BodyParts3D/Anatomography 4.3 full-resolution candidate** — очень интересный по сегментации, но до решения provenance/license не production source.
6. **HRA** — benchmark качества происхождения и экспертного review, но не primary shoulder-muscle atlas.

Ни один кандидат не получает статус «лучший» до одинакового A/B-сравнения плечевых структур.
