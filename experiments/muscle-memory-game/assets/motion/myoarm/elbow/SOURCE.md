# MyoArm elbow Motion Lab runtime

Source: MyoHub/myo_sim
Revision: 93b0ca8f4ec90c9899ee7f05fee561e9911da91b

myoarm-elbow-flexion.json is generated by export-myoarm-elbow.py
from the pinned MuJoCo MyoArm model. It contains source-derived rigid
body transforms and MuJoCo-computed BIClong/BICshort tendon wrapping
segments for elbow flexion.

humerus.stl, ulna.stl, and radius.stl are copied from the same pinned
MyoArm package so motion and displayed bones share one source
coordinate system.

Repository source files declare Apache-2.0. Product use still retains
the project's separate upstream provenance/licensing review gate.
