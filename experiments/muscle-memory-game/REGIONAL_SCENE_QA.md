# QA региональной сцены и послойного изучения

Этот документ фиксирует контракт тренажёра для региональных учебных вставок.

## Региональная сцена

При включённом «Только выбранный блок»:

- мышечная сцена содержит только мышцы текущего учебного блока;
- поиск в атласе не выдаёт мышечные и тканевые структуры из других областей;
- камера фокусируется на выбранном блоке;
- «Шея» и «Шейно-воротниковая зона» являются разными блоками;
- переключение между Z-Anatomy и BodyParts3D сохраняет выбранный блок;
- прогресс мышцы не дублируется между блоками: он хранится как `мышца × навык`.

Курс-ориентированные блоки:
- плечевой пояс;
- верхняя конечность;
- нижняя конечность;
- шея;
- шейно-воротниковая зона;
- стопа;
- мышца, выпрямляющая позвоночник;
- ротаторная манжета плеча;
- лопаточный комплекс.

## Кости и ориентиры

Изолированный регион по умолчанию открывается как чистая мышечная сцена.

Костный слой:
- выключен по умолчанию;
- может быть включён отдельно;
- использует региональную фильтрацию и не должен возвращать весь скелет;
- режим просвечивания остаётся вспомогательным визуальным режимом, а не заявлением о топографической точности.

Нервные, сосудистые и лимфатические ориентиры Z-Anatomy:
- выключены по умолчанию;
- загружаются лениво;
- имеют собственное состояние геометрии и не используют диапазоны костей;
- при региональной изоляции фильтруются пространственным контекстом выбранного блока.

## Послойное изучение

BodyParts3D предоставляет пресеты:
- мышцы;
- кости и мышечные ориентиры;
- кожа и наружные покровы;
- подкожная клетчатка;
- фасции;
- сухожилия и связки;
- мышцы + соединительные ткани.

Дополнительно в режиме атласа доступно «Снять видимый слой»:
- снимаются только реально видимые мышечные структуры текущего ракурса;
- действие остаётся внутри текущего регионального блока;
- один снятый поверхностный слой возвращается одним действием «Вернуть последнюю».

Во время викторины вспомогательные слои временно скрываются, чтобы не перекрывать ответ. После выхода из сессии выбранный до тренировки послойный режим восстанавливается.

## Викторина

- варианты «Назвать» берутся только из текущего учебного блока;
- составные блоки распределяют короткую сессию между своими подрегионами;
- малые блоки предлагают пройти весь блок целиком;
- «Найти» и «Назвать» учитываются независимо;
- итог смешанной сессии отдельно показывает результат локализации и называния;
- контроль не допускает задания «Найти», если целевая мышца недоступна для честного клика.

## Cross-source gate

Для мышечного понятия, которое присутствует одновременно в Z-Anatomy и BodyParts3D, обе модели должны одинаково определять принадлежность к учебному блоку.

Разная полнота исходных атласов допускается и регистрируется отдельно; она не маскируется искусственным добавлением отсутствующей геометрии.

## Что этот gate не доказывает

Региональный QA проверяет программную группировку, интерфейс и визуальную изоляцию. Он не заменяет поструктурную анатомическую валидацию геометрии. Статус `verified_for_teaching` присваивается отдельно по правилам `ANATOMY_QUALITY.md`.


## Смена анатомического источника

Переключение BodyParts3D ↔ Z-Anatomy:
- сохраняет выбранный учебный блок и накопленный прогресс;
- сбрасывает несовместимый визуальный пресет к «Мышцы»;
- не переносит прозрачность, фасциальный, кожный или соединительнотканный режим в источник, где такого слоя нет;
- после загрузки заново применяет региональную изоляцию и фокус.
