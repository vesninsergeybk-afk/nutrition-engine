# План заполнения справочных карточек мышц

Актуальная контрольная точка: 29.09.2026.

Источник истины для реализации: `feature/muscle-memory-mvp`. В `release/static-atlas-v1` попадает только проверенное состояние.

## Критерий готовой карточки

Карточка мышцы считается закрытой, когда:
- есть русское и латинское название;
- проверены начало, прикрепление, функции и иннервация;
- направление волокон указано там, где оно имеет учебный смысл;
- позиционно-зависимые функции не превращены в безусловные;
- указаны синергисты и антагонисты там, где их можно определить корректно;
- если прямого антагониста нет, это сказано прямо;
- есть минимум одна `asset-ready` иллюстрация, достоверно показывающая именно эту мышцу;
- источник и права изображения проверены;
- 3D-сопоставление не подменяет отсутствующую структуру соседней геометрией;
- нет пустых заглушек и дублирующих карточек;
- спорные и легко ломаемые решения защищены тестом.

Групповые записи и анатомические комплексы учитываются отдельно и не должны искусственно увеличивать число незаполненных мышц.

## Очередь дальнейших проходов

### A. Голень и стопа
1. popliteus + глубокая задняя группа голени;
2. короткие разгибатели на тыле стопы;
3. первый подошвенный слой;
4. второй подошвенный слой;
5. третий и четвёртый подошвенные слои;
6. сверка вариабельных и редуцированных структур стопы.

### B. Второй справочный проход по уже проиллюстрированным областям
Пройти спину и плечевой пояс, грудную клетку и живот, глазницу, верхнюю конечность и поверхностные мышцы тазового дна. Добавить недостающие `sourceNotesRu`, перепроверить функциональные связи и формулировки действий.

### C. Голова и шея
Разбить на: мимические → жевательные → поверхностные мышцы шеи → надподъязычные → подподъязычные → лестничные и предпозвоночные → подзатылочные.

### D. Глубокие структуры головы и шеи
Разбить на: наружные мышцы языка → собственные мышцы языка → мягкое нёбо → глотка → внутренние мышцы гортани.

Для мелких структур использовать изображения, где нужная мышца подписана или выделена. Общая пластина не прикрепляется к карточке только ради заполнения галереи.

### E. Финальный cross-region audit
- 100% мышечных записей имеют готовую иллюстрацию либо документированное обоснование её отсутствия;
- нет карточок с изображением соседней мышцы;
- нет пустых `assetPath`;
- начало, прикрепление, действие и иннервация заполнены;
- функциональные связи проходят тесты;
- двусторонние 3D-mesh корректно сводятся к одной учебной цели;
- глубокие мышцы можно открыть в режиме «Найти» без ошибочного штрафа за навигацию.

## Правило небольших проходов

Один проход — один связный анатомический блок примерно из 2–6 мышц:
1. проверка данных и лицензий;
2. fast-suite;
3. при необходимости один целевой browser-smoke;
4. только после зелёной проверки — fast-forward `release/static-atlas-v1`.

Следующий блок выбирается по анатомической связности, а не по принципу «где проще найти картинку».
