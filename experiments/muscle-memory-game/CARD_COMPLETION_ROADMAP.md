# План заполнения справочных карточек мышц

Этот файл оставлен как совместимый указатель.

**Единый актуальный источник истины:** `REFERENCE_CARD_ROADMAP.md`.

Именно там фиксируются:
- критерий готовой мышечной карточки;
- актуальное покрытие по регионам;
- очередь следующих проходов;
- правила проверки 2D/3D-сопоставлений;
- порядок fast-suite / целевых browser-smoke / обновления `release/static-atlas-v1`.

Не дублировать здесь численность мышц, статус регионов или очередь работ: они должны редактироваться только в `REFERENCE_CARD_ROADMAP.md`.
