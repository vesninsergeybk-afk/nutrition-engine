Анатомическая модель

BodyParts3D объединяет тканевые слои 4.0 с проверенными мышцами из 3.0. Для отдельных регионов дополнения включаются только после проверки совмещения.

Анатомический контекст

Мышцы остаются основной непрозрачной и кликабельной моделью.

Дополнительные ткани

Включайте только нужные структуры. Они показываются поверх мышц и остаются выбираемыми.

Во время тренировки дополнительные ткани временно скрываются, чтобы не перекрывать мышечную цель.

Ориентиры безопасности

Нервные, сосудистые и лимфатические ориентиры доступны в Z-Anatomy и загружаются по выбору. Структуры с проверенным русским названием можно выбирать на модели и находить через поиск; остальные остаются фоновым анатомическим контекстом.
