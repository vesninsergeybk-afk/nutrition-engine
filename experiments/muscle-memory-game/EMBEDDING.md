# Встраивание анатомического тренажёра в учебные блоки

Тренажёр поддерживает прямой вход в учебный блок через query-параметры. Это позволяет одной и той же версии тренажёра использовать общий прогресс ученика, но открываться в контексте конкретного урока или регионального модуля.

## Основные параметры

- `embed=1` — компактный режим для встраивания.
- `scope=<id>` — учебный блок.
- `practice=find|name|practical|mistakes|exam` — предвыбранный режим практики.
- `size=5|10|20` — желаемое число заданий, если такой размер доступен для выбранного блока.
- `mode=explore` — открыть атлас вместо тренировки.

Автоматический старт намеренно не используется: ученик видит выбранный блок и сам запускает сессию.

## Учебные блоки

| ID | Название | Состав |
| --- | --- | --- |
| `shoulder` | Плечевой пояс | Мышцы плечевого пояса |
| `upper-limb` | Верхняя конечность | Плечевой пояс, плечо, предплечье и кисть |
| `lower-limb` | Нижняя конечность | Ягодичная область, бедро, голень и стопа |
| `neck-collar` | Шейно-воротниковая зона | Шея, подзатылочная область, лопаточно-шейный переход |
| `foot` | Стопа | Собственные мышцы стопы |
| `erector-spinae` | Мышца, выпрямляющая позвоночник | Iliocostalis, longissimus, spinalis |
| `rotator-cuff` | Ротаторная манжета плеча | 4 мышцы ротаторной манжеты |
| `scapular-stabilizers` | Лопаточный комплекс | Трапециевидная, ромбовидные, передняя зубчатая, поднимающая лопатку |
| `all` | Всё тело | Весь учебный каталог |

Старый параметр `region=shoulder` сохраняется для обратной совместимости, но для новых вставок следует использовать `scope`.

## Примеры

Плечевой пояс, смешанная практика:

```
?embed=1&scope=shoulder&practice=practical&size=10
```

Стопа, распознавание по выделенной мышце:

```
?embed=1&scope=foot&practice=name&size=5
```

Комплекс мышцы, выпрямляющей позвоночник, режим «найти»:

```
?embed=1&scope=erector-spinae&practice=find
```

Региональный атлас без запуска викторины:

```
?embed=1&mode=explore&scope=upper-limb
```

## Принцип прогресса

Учебный блок не создаёт отдельную копию мышцы. Прогресс хранится на уровне `мышца × навык`; поэтому результат по одной и той же мышце переносится между всеми блоками, куда она входит.
