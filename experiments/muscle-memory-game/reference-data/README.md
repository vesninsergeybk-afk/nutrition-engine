# Muscle reference data

Эта папка — независимый слой справочных данных для анатомического тренажёра.

## Граница ветки

Ветка `feature/muscle-reference-data` не меняет текущий интерфейс тренажёра и не должна править:
- `app.js`;
- `index.html`;
- стили интерфейса;
- 3D-загрузчики;
- существующий `muscle-reference-data.js`.

До завершения параллельной работы над интерфейсом здесь добавляются только:
- проверенные анатомические данные;
- связи «мышца — область — слой — ориентиры»;
- указатели на иллюстрации;
- сведения об источниках и статусе проверки;
- автоматические проверки целостности данных.

Интеграция в основной интерфейс выполняется отдельным проходом после стабилизации рабочей ветки тренажёра.

## Принцип наполнения

Справочник не копирует учебник дословно. Из источников извлекаются факты, затем они нормализуются и сверяются.

Для каждой мышцы достаточно хранить сведения, которые помогают:
1. узнать структуру;
2. понять её положение и слой;
3. связать мышцу с костными ориентирами;
4. понять направление волокон и основные движения;
5. увидеть отношения с соседними структурами;
6. подобрать корректную иллюстрацию.

Иннервация и кровоснабжение допускаются как расширенные поля, но не обязаны перегружать основную учебную карточку.

## Проверка источников

Основной учебный источник на первом проходе — «Миология» ИГМА (2018). Он очень содержателен, но не принимается как безошибочный источник. Спорные места сверяются с академическими атласами и современными анатомическими источниками.

Материалы курса (анатомические карты модулей 5–7) задают педагогический объём: слои, крупные ориентиры, функции через движение, отсутствие ложной точности при пальпации глубоких структур.

Материалы, содержащие диагностические или лечебные утверждения, не используются как источник анатомических фактов без отдельной проверки.

## Иллюстрации и права

Наличие изображения в библиотеке не означает разрешения на его публичное встраивание.

Для каждого изображения хранится `rightsStatus`:
- `public-domain` — можно включать после проверки конкретного файла;
- `owned` — собственный материал проекта;
- `licensed` — есть подходящая лицензия;
- `review` — разрешение на публичное использование не подтверждено;
- `generated` — изображение создано специально для проекта и прошло анатомическую проверку.

Файл со статусом `review` не получает публичный `src`. Валидатор контролирует это правило.

## Текущий пилот

Первый набор выбран по реальным пробелам тренажёра:
- широчайшая мышца спины;
- передняя зубчатая мышца;
- наружная косая мышца живота;
- жевательная мышца.

После проверки схемы каталог расширяется по регионам, а не случайным списком мышц.
