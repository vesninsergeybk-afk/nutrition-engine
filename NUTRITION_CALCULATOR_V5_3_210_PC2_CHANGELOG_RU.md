# Changelog v5.3.210-pc2

## Product Focus

- Добавлен блок «Главные приоритеты».
- Итог ограничен пятью действиями и не повторяет полные таблицы.
- Приоритеты формируются из наиболее значимых отклонений КБЖУ и HEI.
- Дублирующиеся рекомендации объединяются.
- Для черновика и отдельного приёма пищи показываются только действия по корректному завершению ввода.

## Result hierarchy

- «Питательные итоги» и «Качество рациона» разделены на вкладки.
- Вкладка качества заблокирована до подтверждения полного дня.
- При переключении вкладок скрывается неактивная панель, а не создаётся вторая копия результата.
- Печатная версия раскрывает обе панели.

## Search editorial stabilization

Расширены синонимы и generic-first ранжирование для повседневных запросов, включая:

- яйцо;
- хлеб;
- сыр;
- кофе;
- яблоко;
- лосось и рыбу;
- овсянку и рис;
- картофель;
- кефир и сметану;
- индейку, говядину и свинину;
- макароны;
- помидоры, огурцы и брокколи.

В простом режиме карточки поиска стали компактнее; расширенная подготовительная информация сохранена в профессиональном режиме и в доступных контролах.

## Release infrastructure

- release version переведён на `v5.3.210-pc2`;
- создан PC2 runtime manifest и CSS bundle;
- validation evidence package перепривязан к хэшам PC2 без изменения статуса `EXTERNAL_VALIDATION_PENDING`;
- modern и legacy controller синхронизированы;
- добавлены PC2 static и Chromium regression suites;
- manifest и SBOM дополнены метаданными product-focus слоя.

## Сохранённые границы

- нормативы P1.2 не изменялись;
- продуктовые числовые данные P1.3 не изменялись;
- формульный реестр P1.4 не изменялся;
- внешний validation status остаётся pending;
- PC2 не выдаётся за результат пользовательского исследования.
