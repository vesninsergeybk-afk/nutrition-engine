# RC2 Hosting Hotfix 1 — публикация

1. Не копировать поверх текущей папки RC2.
2. Создать новый чистый каталог и распаковать HOSTING ZIP целиком.
3. Убедиться, что загружены папки `assets`, `data`, `api` и файлы `index.html`, `.htaccess`, `_headers`, `robots.txt`.
4. Открыть сайт в приватной вкладке либо очистить данные сайта, чтобы исключить старый bootstrap из кэша.
5. Первый запуск на медленном соединении может занять дольше повторных запусков.
6. При ошибке раскрыть «Технические сведения»: новая версия должна показать конкретную причину.
