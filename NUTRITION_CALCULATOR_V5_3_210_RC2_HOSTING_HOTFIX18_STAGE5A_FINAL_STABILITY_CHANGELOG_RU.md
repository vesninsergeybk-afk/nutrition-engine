# HOTFIX18 Stage 5A Final Stability — журнал изменений

## Исправления приложения

- Создан `81-workspace-profile-needs-v5.3.210-rc2-hf18.js` для modern- и legacy-runtime.
- Записи текста, атрибутов, классов и `hidden` в блоке профиля переведены на идемпотентные помощники: DOM меняется только при фактическом отличии нового значения.
- Наблюдатель профиля сохранён: он по-прежнему реагирует на реальные внешние изменения, но больше не запускает сам себя без необходимости.
- Создан `60-norm-region-clarity-v5.3.210-rc2-hf18.js` для modern- и legacy-runtime.
- Уже обёрнутый `State.setRegion` теперь считается готовым состоянием.
- Загрузочный опрос нормативного модуля запускается только при реальной неготовности зависимостей и прекращается после их готовности.
- Добавлен кэш нормализованного HTML сравнительных таблиц, исключающий повторную запись идентичной разметки.
- Добавлен self-test профиля HOTFIX18.

## Исправления runtime и упаковки

- Активная версия повышена до `v5.3.210-rc2-hf18`.
- Активный `index.html` и `index-v5.3.210.html` переведены на runtime-manifest и CSS-bundle HOTFIX18.
- Hosting-self-test приведён к реальным активным файлам: навигация остаётся HF17, профиль и нормативное сравнение — HF18.
- В историческом разделе манифеста HOTFIX17 восстановлены реальные пути файлов HF17; несуществующие навигационные файлы HF18 больше не заявляются.
- Добавлен отдельный раздел манифеста `workspace_hotfix18_stage5a_final_stability`.
- Runtime closure повторно рассчитан и содержит 277 необходимых файлов без пропусков.

## Усиление тестового контура

- Добавлен контракт `stage-5a-final-stability-contract.json`.
- Добавлены статический тест, Chromium-прогон и проверка доказательств HOTFIX18.
- Новый тест наблюдает весь документ, а не только навигационные атрибуты.
- Повторный рендер профиля и нормативного сравнения проверяется серией из 100 вызовов.
- Исторические тесты обновлены так, чтобы проверять сохранение старых контрактов в текущем релизе, не требуя, чтобы номер текущей сборки оставался HF17.
- Тест 4.6 теперь нажимает кнопку именно ожидаемого продукта, а не первую карточку выдачи.
- В тесте 4.6 отделена реальная история URL от режима `set_content`: среда `about:blank` больше не выдаётся за полноценную проверку back/forward.

## Что намеренно не менялось

Расчёты, формулы, нормативные значения, продукты, модель рациона, HEI, коррекция и отчёт не изменены. Этап 5Б не выполнялся.
