# Этап 5А-H. Приёмка HOTFIX18 на реальном hosting-адресе

## Решение о следующем шаге

После локальной стабилизации HOTFIX18 преждевременно переходить к этапу 5Б и удалять старые зависимости нельзя. Следующий обязательный барьер — проверить неизменённую hosting-сборку в тех условиях, которые невозможно полноценно воспроизвести во встроенном документе: на настоящем HTTPS-адресе, с реальной историей браузера, перезагрузкой, политиками сервера и системной печатью.

Этот этап не добавляет функций и не меняет расчётное ядро. Его назначение — подтвердить готовность HOTFIX18 к периоду стабильности и подготовить доказательную основу для отдельного решения о начале 5Б.

## Граница этапа

Выполняются:

1. Проверка распакованного hosting-архива через Apache.
2. Проверка версии интерфейса и базовой версии API.
3. Проверка заголовков безопасности, кеширования и запрета служебных поверхностей.
4. Репетиция атомарного развёртывания и отката.
5. Повторный Chromium-прогон повседневного цикла и состояния покоя.
6. Проверка отдельного документа единого отчёта и его PDF, а не печати всей страницы приложения.
7. Подготовка внешних runner-сценариев для Chromium, Firefox и WebKit.
8. Подготовка ручной матрицы TalkBack, VoiceOver, масштаба текста, мобильных панелей и системной печати.
9. Предварительная инвентаризация кандидатов этапа 5Б без удаления файлов.

Не выполняются:

- удаление резервного полотна;
- удаление старых обработчиков и DOM-зависимостей;
- изменение формул, нормативов, базы продуктов, HEI или коррекции;
- присвоение новой версии приложению без изменения runtime-кода;
- утверждение этапа 5Б до внешней приёмки.

## Автоматическая внешняя проверка

После размещения архива на тестовом HTTPS-адресе выполнить из корня полного приватного комплекта:

```bash
python3 tools/remote_smoke_stage5a.py \
  https://STAGING_HOST \
  --expected-ui v5.3.210-rc2-hf18 \
  --expected-api v5.3.210-rc2 \
  --json-out reports/stage-5a-external-smoke.json
```

Затем выполнить браузерный сценарий в каждом доступном движке:

```bash
python3 tools/stage_5a_hosting_browser.py \
  https://STAGING_HOST \
  --engine chromium \
  --json-out reports/stage-5a-external-chromium.json \
  --pdf-out reports/stage-5a-external-chromium-report.pdf

python3 tools/stage_5a_hosting_browser.py \
  https://STAGING_HOST \
  --engine firefox \
  --json-out reports/stage-5a-external-firefox.json \
  --pdf-out reports/stage-5a-external-firefox-report.pdf

python3 tools/stage_5a_hosting_browser.py \
  https://STAGING_HOST \
  --engine webkit \
  --json-out reports/stage-5a-external-webkit.json \
  --pdf-out reports/stage-5a-external-webkit-report.pdf
```

При наличии Node-зависимостей из полного приватного комплекта можно дополнительно использовать Playwright-spec:

```bash
NUTRITION_STAGING_URL=https://STAGING_HOST \
  npx playwright test tests/e2e/stage-5a-hosting-acceptance.spec.js \
  --project=chromium
```

Тот же сценарий повторяется для `firefox` и `webkit`.

## Ручная матрица

На реальных устройствах пройти один и тот же цикл:

**профиль → потребности → 5–7 продуктов подряд → изменение граммовки → анализ → показатель и вкладчики → «Улучшить» → предпросмотр → применение → откат → отчёт → системная печать/PDF → возврат к рациону.**

Обязательные среды:

- Android + Chrome + TalkBack;
- iPhone/iPad + Safari + VoiceOver;
- Firefox на настольной системе;
- Safari/WebKit на macOS или iOS;
- увеличение текста до 200%;
- появление и скрытие адресной и нижней панели мобильного браузера;
- системный диалог печати и сохранения PDF.

## Критерии допуска к периоду стабильности

Допуск возможен, когда одновременно выполнены условия:

- все автоматические проверки staging-адреса имеют статус `PASS`;
- нет потери рациона, профиля, маршрута или параметров URL;
- кнопки браузера «Назад» и «Вперёд» восстанавливают реальные URL и представления;
- `?ui=long` доступен только как технический резерв и не сохраняется как обычный режим;
- после выхода из резерва восстанавливается последний рабочий маршрут;
- отчёт и системный PDF содержат один единый документ без обрезанных столбцов и посторонних разделов;
- в Firefox, WebKit, TalkBack и VoiceOver нет блокирующих или существенных проблем;
- при масштабе текста 200% сохраняются доступность действий и отсутствие горизонтального переполнения;
- атомарный откат подтверждён.

## Критерии начала этапа 5Б

Этап 5Б не начинается автоматически после приёмки. Для него требуется отдельное решение, основанное на:

- внешней staging-приёмке без блокирующих и существенных дефектов;
- нескольких полноценных рабочих сессиях;
- отсутствии пользовательской необходимости возвращаться к резервному полотну;
- подтверждённой карте 277 активных runtime-файлов;
- отдельной классификации 489 недостижимых исходных кандидатов: удалить, архивировать или сохранить как историческое доказательство.
