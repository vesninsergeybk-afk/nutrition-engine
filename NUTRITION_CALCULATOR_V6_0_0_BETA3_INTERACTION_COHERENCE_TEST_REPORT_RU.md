# Отчёт о тестировании V6 Beta 3

- Единый контракт состояний: 8/8.
- Сохранение и восстановление профиля: 4/4.
- Полная аналитическая цепочка: 6/6.
- Desktop/mobile и три темы: 6/6.
- Расширенные UX-сценарии: 7/7.
- Обзор нутриентов по группам: 5/5.
- Фото, голос и аудиоввод Gemini: 7/7.

## Статические и архитектурные проверки

- Release audit: 52/52.
- Синтаксис изменённых и генерируемых JS/PHP: 17/17.
- Runtime closure: 315 файлов, отсутствующих зависимостей нет.
- Защищённое ядро: 184/184 файла побайтно совпадают с Beta 2.
- База продуктов: 1105.
- Идемпотентность генератора: 11 файлов, повторный запуск не меняет результат.
- Добавочный объём: 24 299 байт без стороннего UI-framework.

## Методика

Браузерные тесты выполнялись в независимых Chromium-контекстах. Проверялись вычисленные стили, ARIA-состояния, доступность с клавиатуры, размеры мобильных целей, восстановление профиля, наличие полной аналитики и отсутствие горизонтального переполнения.

После сборки тот же набор ключевых тестов повторяется на чисто распакованном hosting-архиве.

## Внешние ограничения

Контейнер не заменяет физические Android/iPhone, Safari, Samsung Internet и Qt WebEngine. Успешная обработка ответа Gemini подтверждена mock-провайдером; живой ответ Google зависит от сетевого доступа реального HTTPS-хостинга.

## Финальная гонка поисковой выдачи

При одновременном полном прогоне обнаружено, что исторический поисковый рендерер мог после первичного ограничения снова снять `hidden` с карточек. Исправление проверено по вычисленному `display`: сначала видны 8 результатов, после команды «Показать ещё» — 16, а при переходе в Modern — все 34.
