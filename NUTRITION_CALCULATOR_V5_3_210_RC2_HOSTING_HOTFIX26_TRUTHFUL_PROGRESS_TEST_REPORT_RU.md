# Отчёт о проверке HOTFIX26

## Итог

Сборка принята. Заставка связана с фактическими стадиями запуска и сохраняет быстрые сжатые пакеты HOTFIX24.

## Браузерные сценарии

Пройдены пять сценариев загрузки:

- обычный запуск — заставка 4250 мс;
- замедленная база продуктов — 5548 мс;
- замедленный runtime — 4205 мс;
- отказ сжатой базы с переходом на запасной пакет — 4335 мс;
- отказ сжатого runtime с переходом на запасной пакет — 4239 мс.

Во всех сценариях последовательно отображались стадии «Интерфейс», «База продуктов», «Расчёты и инструменты», «Проверка готовности» и «Готово». Прогресс был монотонным, база содержала 1105 продуктов, четыре финальные проверки завершились успешно.

## Фото и голос

Пройдены три сценария:

- фотография выбирается и подготавливается одним нажатием;
- запись голоса запускается одним запросом `getUserMedia({ audio: true })`;
- запрет микрофона отображается понятным сообщением.

## Регрессия

- 22 проверки контракта загрузчика — успешно;
- 13 проверок релизной целостности — успешно;
- 108 проверок формул — успешно;
- 74 проверки нормативного реестра — успешно;
- 297 файлов входят в полное runtime-замыкание, отсутствующих файлов нет;
- 954 общих файла относительно HOTFIX25 побайтово идентичны.
