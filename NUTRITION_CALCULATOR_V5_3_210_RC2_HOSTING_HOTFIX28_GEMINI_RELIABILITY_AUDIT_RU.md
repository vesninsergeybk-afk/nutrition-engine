# Аудиторский отчёт HOTFIX28

## Решение

HOTFIX28 допускается к использованию как расчётно-нейтральное исправление надёжности Gemini и медиа-ввода. Оба приватных архива намеренно включают существующие основной и резервный ключи в защищённом серверном файле `api/gemini-secret.php`, чтобы Gemini работал сразу после распаковки.

## Что проверено

- формулы, нормативы, HEI и продуктовые данные не изменены;
- база содержит 1105 продуктов;
- runtime closure содержит 300 файлов и не имеет отсутствующих зависимостей;
- `api/utf8-safe.php`, `api/gemini-secret.php` и `api/.htaccess` входят в hosting runtime;
- все активные PHP- и JavaScript-файлы проходят синтаксическую проверку;
- обычный совершеннолетний пользователь не обязан подтверждать профессиональную цель;
- клинические профили по-прежнему блокируют внешний AI;
- фото не переводит микрофон в ложное активное состояние;
- отказ микрофона сохраняется после ленивой загрузки модуля;
- состояния действий обозначаются текстом, ARIA-атрибутами и визуальными признаками;
- встроенный файл содержит основной и резервный ключи;
- файл имеет прямой PHP-guard, возвращающий 404;
- запрет доступа продублирован в корневой `.htaccess` и `api/.htaccess`;
- режим файла в архиве установлен как `0600`;
- значения ключей отсутствуют во всех остальных файлах;
- health-ответ сообщает только `configured: true` и не раскрывает значения;
- переменные окружения и внешний файл остаются поддерживаемыми приоритетными переопределениями.

Финальный специализированный аудит: **57/57 проверок**.

## Правки по итогам повторных проходов

1. Исправлена UTF‑8-обрезка без зависимости от `mbstring`.
2. Ошибка без медиафайла заменена на HTTP 422 `media_missing`.
3. Состояния фотографии отделены от состояния микрофона.
4. Состояние отказа микрофона восстанавливается после ленивой инициализации.
5. Согласие адаптировано для обычного совершеннолетнего немедицинского использования.
6. Существующие ключи восстановлены в приватной серверной сборке по требованию владельца проекта.
7. Добавлен прямой guard в `api/gemini-secret.php`.
8. Добавлена дополнительная `api/.htaccess`.
9. Runtime inventory и сборщик изменены так, чтобы файл с ключами не удалялся при последующих пересборках.
10. Верификатор допускает ключи только внутри `api/gemini-secret.php` и отклоняет их появление в любом другом файле.
11. Добавлена HTTP-проверка: встроенные ключи активны, прямой доступ закрыт, ответы их не раскрывают.
12. Настоящий WAV повторно отправлен через endpoint именно со встроенным комплектом ключей.

## Внешнее ограничение

Контейнер не разрешает DNS-имя `generativelanguage.googleapis.com`, поэтому успешный внешний ответ Gemini не получен. Подтверждены:

- корректная загрузка встроенного основного и резервного ключей;
- достижение транспортного слоя;
- отсутствие прежней UTF‑8-ошибки;
- корректная обработка транспортной ошибки;
- полный успешный путь с контролируемым ответом провайдера.

Один живой запрос на реальном HTTPS-хостинге остаётся эксплуатационной проверкой, а не исправлением кода.

## Эксплуатационное правило

После распаковки приватного пакета загруженный ZIP необходимо удалить из публично доступного каталога. Сам `api/gemini-secret.php` оставляется на сервере: он нужен для штатной работы Gemini. Перевыпуск существующих ключей только из-за их нахождения в приватных проектных материалах не требуется.
