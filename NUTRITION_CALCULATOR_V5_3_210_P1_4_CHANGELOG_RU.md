# Changelog P1.4 — Formula Registry & Independent Golden Cases

Версия: `v5.3.210-p1.4`  
Дата: 18 июля 2026 года

## Добавлено

- канонический реестр из 29 материальных формул и правил;
- 113 независимых golden cases;
- независимый Python-анализатор эталонных случаев;
- CSV-матрица покрытия формул;
- runtime API `NutritionFormulaRegistryP14`;
- P1.4 QA API для расчёта потребностей;
- formula provenance для потребностей, защищённых режимов, продуктовой арифметики и HEI;
- browser-suite P1.4;
- отдельный P1.4 quality gate;
- формульная трассировка в итоговом пользовательском отчёте;
- modern- и legacy-копии сгенерированного runtime registry.

## Исправлено

- удалена неиспользуемая дублирующая реализация Mifflin–St Jeor;
- устранено двойное создание QA-интерфейса расчёта потребностей;
- заменён устаревший protein self-test с ожиданиями от старой модели;
- устаревшие CKD/dialysis ожидания больше не маскируются как автоматические текущие цели;
- локальные коэффициенты PAL, цели, белка, жидкости и соли явно помечены как локальные политики;
- protected modes теперь возвращают IDs и версию формул NASEM/EFSA;
- HEI возвращает formula audit;
- расчётный core возвращает provenance масштабирования, salt fallback и суммирования;
- release verifier проверяет P1.4 formula metadata и обязательные файлы;
- итоговый отчёт сохраняет formula audit в неизменяемом report snapshot.

## Не изменено

- значения продуктовой базы P1.3;
- нормативный реестр P1.2;
- пользовательские числовые значения без доказанного дефекта;
- клинические protected modes, где требуется внешняя цель специалиста.

## Совместимость

- сохранено имя `runV44ProteinFormulaTests` как compatibility alias;
- modern и legacy runtime используют идентичную P1.4-логику трассировки;
- существующие P1.2 и P1.3 gates остаются частью release gate.
