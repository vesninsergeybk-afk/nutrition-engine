# Эксплуатация Product Correction / Stabilization PC1

Версия: `v5.3.210-pc1`

## Публикация

Для сервера используется только архив `HOSTING_PRIVATE`. Его содержимое распаковывается в отдельный каталог релиза, после чего переключается document root или симлинк. Не смешивайте файлы PC1 с предыдущей P2.0-папкой.

## Быстрая проверка после публикации

1. Открыть главную страницу без кэша.
2. Убедиться, что отображается beta-граница PC1.
3. Рассчитать потребности на desktop и mobile.
4. Добавить один продукт — состояние должно оставаться черновиком.
5. Убедиться, что HEI не показан как финальный.
6. Подтвердить завершённость дня — HEI должен появиться в диапазоне 0–100.
7. Изменить граммы — анализ должен снова стать предварительным.
8. Переключить «Простой/Профессиональный» режим.
9. Проверить запросы `молоко`, `йогурт`, `творог`, `гречка`, `курица`.
10. Проверить, что статус внешней валидации остаётся `EXTERNAL_VALIDATION_PENDING`.

## Кэширование

PC1 использует новые versioned runtime bundle и manifest. После публикации очистите CDN/server cache только для активных HTML, manifest, CSS bundle и изменённых JS-модулей. Пользовательский hard refresh не должен быть основным способом активации релиза.

## Откат

Сохраните отдельную папку предыдущего P2.0 HOSTING-архива. Откат выполняется переключением document root/симлинка на целую предыдущую папку, а не копированием отдельных файлов поверх PC1.

## Мониторинг

Отслеживайте:

- ошибки расчёта потребностей;
- случаи, когда подтверждение дня не сохраняется;
- неожиданные значения HEI вне 0–100;
- поисковые запросы без подходящих результатов;
- долю пользователей, открывающих профессиональный режим;
- жалобы на непонятную разницу между заполненностью и достоверностью.

Не собирайте ФИО, диагнозы или содержание рационов в аналитические журналы без отдельного правового и privacy-основания.

## Ограничение утверждений

Разрешённая формулировка: внутренне протестированная beta-версия калькулятора с прозрачными ограничениями данных.

Запрещены до принятого внешнего evidence package формулировки «клинически валидирован», «одобрен врачами», «заменяет специалиста» и эквивалентные заявления.
