# V6 Beta 5 — сквозное усиление HOTFIX28–30

Версия: **v6.0.0-beta5-cross-stage-hardening**  
Дата аудита: **5 августа 2026 года**

## Исправлено

- Пять обязательных антропометрических полей подняты в первый экран профиля.
- Панель сохранения, прогресса и основного действия перенесена после самих обязательных полей.
- Методические пояснения перенесены ниже рабочей части.
- На маршруте профиля скрыты пустая строка метрик, аналитическая колонка, мобильная сводка рациона и плавающая панель быстрых действий.
- Удалено перекрытие элементов профиля плавающими командами.
- Ссылки быстрого перехода в обычном, критическом, отложенном и сжатом runtime направлены на поле «Пол», а не на необязательное имя.
- Сжатый deferred runtime пересобирается детерминированно и получает версию Beta 5.
- Исправлены package.json/package-lock.json, название приложения, версия, runtime manifest и конфигурация.
- Удалено устаревшее описание `secret-free packaging`; приватная серверная поставка намеренно содержит защищённые ключи Gemini.
- Исправлен дублирующий атрибут `data-ivory-target`.
- Удалены повторяющиеся cache-control meta-теги.

## Не изменялось

Формулы, нормативы, продуктовые данные и 184 защищённых файла расчётного ядра побайтно совпадают с Beta 4. База содержит 1105 продуктов.
