# Протокол независимой проверки Android-альфы

## Блок 1. Автономность
1. Установить APK, открыть, закрыть.
2. Включить режим полёта.
3. Создать профиль и рацион; рассчитать потребности, БЖУ, нутриенты, HEI.
4. Завершить приложение и открыть снова — профиль и рацион остаются.
5. Экспортировать JSON, очистить данные, импортировать — содержимое совпадает.
6. Сохранить отчёт как PDF средствами Android.
Отдельно проверить, что APK не содержит INTERNET permission.

## Блок 2. Сравнение расчётов
Для одинаковых входных JSON сравнить веб-ядро и Android по всему набору
выходных полей, включая граничные случаи и клинические предупреждения.
Допуск на расхождение вычислений — **ноль**. Округление отображения
проверять отдельно от числовых значений.

## Блок 3. Мобильное взаимодействие
Проверить ширины экрана 320/360/390/432 dp, клавиатуру,
системный масштаб шрифта 100–200%, портрет/ландшафт, жест «назад»,
нижнюю навигацию, клавиатурный фокус, TalkBack. Никакая кнопка
не должна перекрывать нужное поле или оставаться недоступной.

## Блок 4. Фото/голос
Фото: проверять реальные блюда с известным названием, способом
приготовления и массой. Учитывать ложноположительные подсказки,
неизвестные блюда и время обработки.
Голос: до включения модели тест не пройден; замена сервера
системным микрофоном без локально упакованных весов недопустима.

## Блок 5. Подпись и обновление
Проверить повторную установку поверх предыдущей версии:
версия подписи и данные пользователя должны сохраняться.
Ключ выпуска хранится вне репозитория.
