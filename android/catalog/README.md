# Публичный канал базы Nutrient

`latest.json` указывает на сжатый архив `catalog-<sha256>.json.gz`.
Версия содержимого хранится в `jsonSha256` и `version`. В APK также лежит
встроенная копия этого же каталога. Обновление изменяет только базу продуктов.

После проверки дополнений запустите `python3 android/tools/publish_catalog.py`
и опубликуйте обновлённый указатель и новый архив в стабильной ветке
`nutrient-catalog`. Старые архивы удалять не требуется: они дают возможность
проверить происхождение предыдущих версий.

Не публикуйте в этой папке пользовательские рационы, ключи, файлы подписи APK
или исполняемый код, поступающий в приложение по сети.
