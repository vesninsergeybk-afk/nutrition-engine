# HOTFIX12 STAGE 3B — отчёт о тестировании

## Специализированные проверки

Статический контракт этапа 3Б:

- расширение HOTFIX11 без второго расчётного механизма;
- замена и добавление;
- один активный вариант;
- максимум три кандидата;
- ограниченный предварительный поиск;
- канонические снимки и полный HEI;
- явное применение, второе подтверждение и отмена;
- транзакционное применение и транзакционная отмена замены;
- фильтр качества данных;
- конкретные количества в карточках;
- отсутствие фиксированного второго мобильного слоя.

Результат: **19 из 19**.

Алгоритмические сценарии на изолированной модели:

- солёный сыр заменяется продуктом той же пищевой роли;
- соль не предлагается как замена сыру;
- для клетчатки выбирается правдоподобный источник;
- продукт с отклонённым качеством данных не предлагается;
- число кандидатов не превышает трёх.

Результат: **5 из 5**.

Регрессия HOTFIX11:

- контракт интерфейса: **24 из 24**;
- алгоритмические правила: **14 из 14**.

## Общий не браузерный проход

Пройдены генерация и согласованность нормативов, формул, продуктового происхождения, runtime-манифеста, навигации, профиля, рациона, анализа, HEI, защищённых режимов, серверных ограничителей, CSRF, хранения, версий, hosting-check, прав файлов и Apache staging.

Отдельный статический аудит выполнил **2631 утверждение** без ошибок. Остальные специализированные и инфраструктурные наборы также завершились успешно.

## Браузерные сценарии

Подготовлены E2E-сценарии:

1. замена продукта, применение и точная отмена;
2. добавление продукта, применение и точная отмена.

В текущей среде Chromium зависает до начала исполнения Playwright-теста. По этой причине свежий браузерный результат не заявляется. Сценарии включены в полный архив и в CI-профиль для Chromium, Firefox и WebKit.

## Вердикт

Статическая, алгоритмическая, серверная и упаковочная готовность подтверждена. Для окончательной межбраузерной приёмки требуется штатный CI-прогон и ручная проверка мобильных экранных дикторов.
