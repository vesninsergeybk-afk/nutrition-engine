## Цель

Закрыть только те пробелы в 33-польном нутриентном контракте, которые можно заполнить из **явно разрешённой точной эквивалентной строки того же продукта и состояния**.

Запрещено:
- подставлять 0 вместо `null`;
- брать значение из похожего, но не тождественного продукта;
- смешивать raw/cooked/salted/dry состояния;
- расширять семантику продукта ради полноты;
- перезаписывать уже существующее ненулевое или нулевое значение.

## Контракт

Использован отдельный staging-контракт:
`config/external-food-step4c-missing-nutrient-contract-v15.json`.

Разрешены точные доноры только для семи семейств масел:
- avocado;
- mustard;
- hazelnut;
- peanut;
- cocoa butter;
- rice bran;
- apricot kernel.

Для каждого донора проверяются:
- принадлежность тому же family ID;
- одинаковый variant signature;
- ожидаемое официальное название строки;
- заполнение только тех полей, которые до 4В были `null`.
