# Развёртывание v6.0.0 Beta 1 Profile Continuity

1. Загрузите приватный hosting-архив на сервер.
2. Распакуйте его в каталог приложения, заменив файлы предыдущей V6 Alpha 1.
3. Удалите загруженный ZIP из публичного каталога после распаковки.
4. Убедитесь, что сервер исполняет PHP и не отдаёт `.php` как текст.
5. Не удаляйте `api/gemini-secret.php`: в нём находятся существующие основной и резервный ключи Gemini.
6. Откройте приложение один раз с обычной перезагрузкой. При подозрении на смешанный кэш используйте `?safe-ui=1`.

## Быстрая проверка после загрузки

- Новый пользователь видит первым раздел профиля и 0 из 5 заполненных данных.
- После заполнения профиля кнопка «Рассчитать и перейти к рациону» открывает рацион.
- После перезагрузки профиль и продукты восстанавливаются.
- В разделах анализа открываются HEI, нутриенты и Гарвардская тарелка.
- Фото и голос доходят до Gemini без сообщения «ключ не настроен».
- Прямой запрос к `/api/gemini-secret.php` возвращает пустой 404.

## Обновление и откат

Данные профиля и рациона находятся в браузере и переживают замену файлов приложения. Для аварийного входа в устойчивую тему используйте `?safe-ui=1`. Для полного отката храните предыдущий hosting-архив отдельно от публичного web-каталога.
