# V6 Beta 5 — сквозное усиление HOTFIX28–30

Версия: **v6.0.0-beta5-cross-stage-hardening**  
Дата аудита: **5 августа 2026 года**

## Какой архив загружать

Для хостинга используется `NUTRITION_CALCULATOR_V6_0_0_BETA5_CROSS_STAGE_HARDENING_HOSTING_PRIVATE.zip`.

1. Сделайте резервную копию текущего сайта и данных.
2. Загрузите архив в закрытую область либо удалите ZIP сразу после распаковки.
3. Распакуйте с заменой файлов.
4. Убедитесь, что PHP исполняет файлы `api/*.php`, а не отдаёт их как текст.
5. Проверьте `/api/gemini.php`: ответ health не должен содержать ключи.
6. Прямой запрос `/api/gemini-secret.php` должен возвращать 404 с пустым телом.
7. Откройте сайт с `?safe-ui=1`, затем обычный режим и тему Ivory & Brass.
8. Проверьте первый профиль, сохранение после перезагрузки, поиск, фото и голос.

## Ключи Gemini

Существующие основной и резервный ключи входят в приватный серверный файл `api/gemini-secret.php`. Они не должны появляться в HTML, JavaScript, логах или ответах браузеру. Ротация по причине передачи файлов в этом проекте не требуется.

## Откат

Для аварийного визуального входа используйте `?safe-ui=1`. Полный откат выполняется восстановлением резервной копии предыдущего hosting-пакета.
