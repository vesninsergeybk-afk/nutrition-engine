# HOTFIX22 FAST START: размещение на хостинге

## Что загружать

Для публикации используется архив с окончанием `HOSTING_HOTFIX22_FAST_START_PRIVATE.zip`. Содержимое архива нужно распаковать в корень сайта с заменой файлов предыдущей версии.

Не следует переносить поверх новой версии старые `index.html`, `index-v5.3.210.html`, bootstrap, runtime-selector или runtime-manifest.

## Проверка после загрузки

1. Открыть сайт в новой приватной вкладке.
2. Убедиться, что раздел профиля появляется без минутного ожидания полной базы.
3. Ввести имя, рост, массу, возраст и выполнить расчёт.
4. После завершения фоновой подготовки перейти в «Рацион» и найти продукт по слову «молоко».
5. Перезагрузить страницу и убедиться, что повторный запуск проходит быстрее за счёт кэша.

В диагностике браузера активная версия должна быть `v5.3.210-rc2-hf22-fast-start`. Штатный список `loaded_script_requests` содержит критический и отложенный пакеты. Поле `failed_scripts` должно оставаться пустым.

## Серверные требования

- Разрешить отдачу `.js`, `.json`, `.css`, `.png`, `.svg` и `.webmanifest` с корректными MIME-типами.
- Сохранить `.htaccess` и `_headers` из архива.
- Включить gzip или Brotli для JavaScript, JSON, CSS, HTML и SVG.
- Не включать серверную буферизацию, которая ждёт формирования всего ответа перед передачей больших статических файлов.
- После обновления очистить серверный кэш или CDN-кэш для `index.html`; версионированные файлы можно хранить длительно.

## Признаки неполной загрузки архива

Если первый экран не появляется, следует проверить ответы для:

- `assets/runtime/runtime-manifest-v5.3.210-rc2-hf22.js`;
- `assets/runtime/critical-shell-v5.3.210-rc2-hf22.js`;
- `assets/data/products.v5.3.210-p1.3.bundle.js`;
- `assets/runtime/deferred-runtime-v5.3.210-rc2-hf22.js`.

При отсутствии одного из трёх пакетов приложение должно перейти на исходные файлы. Ошибка всей загрузки обычно означает, что одновременно недоступен пакет и его резервные источники либо сервер возвращает HTML вместо JavaScript/JSON.
