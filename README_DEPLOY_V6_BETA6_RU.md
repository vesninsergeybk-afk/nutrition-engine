# Развёртывание V6 Beta 6

1. Используйте архив с суффиксом `HOSTING_PRIVATE`.
2. Распакуйте его в закрытую локальную директорию.
3. Загрузите содержимое в корень HTTPS-сайта.
4. Сохраните права `0600` для `api/gemini-secret.php`.
5. Убедитесь, что сервер исполняет PHP и не отдаёт исходный код PHP как текст.
6. Проверьте `index.html`, профиль, поиск, фото и голос.
7. После извлечения не храните приватный ZIP в публично доступной директории сайта.

Аварийный вход без новой темы: `?safe-ui=1`.
