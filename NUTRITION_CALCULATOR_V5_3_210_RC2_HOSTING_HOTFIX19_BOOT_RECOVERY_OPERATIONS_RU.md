# Развёртывание HOTFIX19 Boot Recovery

## Предпочтительный способ

Полностью распаковать hosting-архив в корень сайта с сохранением структуры каталогов и заменой одноимённых файлов.

После загрузки должны существовать, в частности:

- `index.html`;
- `assets/runtime/runtime-manifest-v5.3.210-rc2-hf19.js`;
- `assets/js/00-runtime-selector-v5.3.210.js`;
- `assets/js/00-runtime-bootstrap-v5.3.210.js`;
- `assets/legacy/js/00-runtime-bootstrap-v5.3.210.legacy.js`.

## Быстрое наложение поверх HF18/5Б.0

Можно использовать отдельный overlay-архив. Он содержит только восемь изменённых или новых файлов. Каталоги внутри архива должны быть загружены с сохранением путей, а `index.html` обязательно заменён.

## После загрузки

1. Открыть сайт в новой приватной вкладке.
2. При необходимости один раз обновить страницу без кэша.
3. Нормальный результат: появляется загрузчик, затем рабочий раздел «Рацион»; экран ошибки не остаётся.
4. При повторной ошибке открыть «Технические сведения». В HOTFIX19 там будут явно указаны ожидаемая версия, версия bootstrap и версия manifest либо конкретный отсутствующий файл.

Старые файлы manifest HF18 могут оставаться на сервере: новый index на них не ссылается. Удалять их до успешной проверки необязательно.
