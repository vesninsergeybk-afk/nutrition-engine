Безопасность сайта

Сайт не содержит форм входа, платёжных форм и запросов банковских реквизитов. Клиентские ресурсы загружаются с того же адреса; функции ИИ вызываются через серверный API с проверкой источника, CSRF-защитой и ограничением размера файлов.

Разрешения

Камера и микрофон разрешены только для текущего сайта и используются после явного действия пользователя. В HF21 программные клики по скрытым элементам выбора файла и записи отключены.

Сообщить о проблеме

При обнаружении уязвимости сообщите владельцу сайта через используемый вами рабочий канал связи и укажите адрес страницы, браузер и последовательность действий.
