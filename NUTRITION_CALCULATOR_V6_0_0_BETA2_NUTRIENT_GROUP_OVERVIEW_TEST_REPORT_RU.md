# Отчёт о тестировании V6 Beta 2

Версия: `v6.0.0-beta2-nutrient-group-overview`

## Целевая приёмка компонента

Результат: **5/5**.

Проверено:

1. количества в обзоре совпадают с канонической полной сводной таблицей;
2. статусы не смешивают достижение RDA/AI с выходом за UL;
3. нажатие на группу открывает правильный фильтр полной таблицы;
4. кольца SVG работают с клавиатуры;
5. мобильная версия остаётся последовательной, текстовой и не имеет горизонтального переполнения.

Дополнительно проверены вычисленные стили: строки имеют светлый фон и читаемый тёмный текст, а мобильная кнопка «Полная таблица» не наследует старую синюю тему.

## Runtime и размер

- runtime closure: 314 файлов, пропусков нет;
- дополнительный объём Beta 2 относительно Beta 1:
  - CSS: 5 376 байт;
  - JavaScript: 7 290 байт;
  - всего: 12 666 байт;
- сторонний UI-framework не добавлялся;
- генератор runtime повторяем: второй запуск не изменяет файлы.

## Внешние ограничения

Контейнер не заменяет проверку системных разрешений на физических Android/iPhone, Safari, Samsung Internet и Qt WebEngine. Обработка ответа Gemini подтверждена mock-провайдером; сетевой ответ Google зависит от доступности API на реальном хостинге.
