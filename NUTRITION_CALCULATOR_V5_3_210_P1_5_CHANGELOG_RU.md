# Changelog P1.5

Версия: `v5.3.210-p1.5`

## Добавлено

- четырёхэтапная навигация «Потребности → Рацион → Анализ → Действия»;
- динамический блок «Что делать сейчас»;
- краткий обзор результата;
- drawer основного итога рациона;
- отдельные drawers альтернативного ввода, расширенной аналитики и AI-планировщика;
- сворачиваемая поисковая выдача;
- вложенное раскрытие детальных HEI-рекомендаций;
- канонический UX-контракт и детерминированный генератор;
- modern/legacy P1.5 runtime-артефакты;
- статические и browser-тесты P1.5;
- UX metadata в release manifest и SBOM-контуре.

## Изменено

- результаты больше не показываются без рациона;
- после расчёта потребностей приоритет автоматически переходит к поиску продуктов;
- после добавления продукта приоритет автоматически переходит к краткому итогу;
- полный HEI и микронутриенты раскрываются по запросу;
- активный runtime bundle увеличен с 27 до 28 CSS-слоёв;
- release identity, health endpoint, hosting-check, retired entrypoints и CI tests обновлены до P1.5;
- runtime closure увеличен с 238 до 242 файлов за счёт четырёх modern/legacy UX-артефактов.

## Исправлено во втором и третьем проходах

- устранён повторный рост страницы после добавления первого продукта;
- UX-контракт включён в legacy closure, а не только в modern-ветку;
- hosting self-test больше не тянет активные P1.4 runtime manifest/bundle;
- release verifier проверяет UX metadata и наличие всех P1.5 артефактов;
- production print сохраняет полное содержание независимо от screen-state drawers.

## Совместимость

Все прежние функциональные возможности сохранены. P1.5 меняет порядок и условия предъявления, но не расчётную семантику.
