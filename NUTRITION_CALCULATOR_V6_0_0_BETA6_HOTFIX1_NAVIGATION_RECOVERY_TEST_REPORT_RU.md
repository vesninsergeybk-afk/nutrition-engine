# Проверка Beta 6 Hotfix 1

## Выполненные проверки

- синтаксическая проверка нового JavaScript через `node --check`;
- проверка состава пакета и точечного характера изменений;
- проверка сохранности `api/gemini-secret.php`, `api/gemini.php` и `api/gemini-guard.php` по SHA-256;
- интеграционный сценарий в реальном Chromium на ширинах 390 и 1440 px с представительным DOM-каркасом оболочки;
- три варианта дизайна видимы, а переключатель перенесён из скрытой панели непосредственно в заголовок;
- «Полотно» активно на мобильной ширине и переводит оболочку в режим `long`;
- «Разделы» возвращают режим `workspace`;
- «Потребности» присутствуют в основной навигации и открывают маршрут `profile`;
- навигация остаётся видимой внутри маршрута потребностей;
- кнопки «Печать» и «Сохранить PDF» расчёта потребностей сохранены.

Полный запуск страницы по локальному URL был заблокирован политикой браузера испытательной среды (`ERR_BLOCKED_BY_ADMINISTRATOR`), поэтому браузерная проверка выполнялась через изолированный интеграционный каркас без подмены логики исправления. Расчётное ядро и серверный контур не менялись.
