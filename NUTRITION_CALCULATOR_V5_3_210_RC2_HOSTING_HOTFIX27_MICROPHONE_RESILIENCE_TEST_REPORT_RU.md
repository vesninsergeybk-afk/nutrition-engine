# Отчёт приёмки HOTFIX27

## Итог

Все обязательные проверки пройдены.

## Микрофон

Проверены шесть отдельных сценариев:

1. успешное разрешение и старт `MediaRecorder`;
2. ложный отрицательный ответ `permissionsPolicy` при фактически доступном микрофоне;
3. отказ пользователя в разрешении;
4. неразрешающийся Promise запроса микрофона;
5. повторное нажатие во время ожидания;
6. отсутствие безопасного контекста или `getUserMedia` с открытием системного диктофона.

Во всех сценариях верхняя карточка показывает состояние. Зависший запрос освобождается для повторной попытки. Вызов микрофона выполняется с совместимым ограничением `{ audio: true }`.

## Фотография

Проверена полная цепочка одним нажатием:

`верхняя кнопка → системный выбор файла → ленивое подключение медиамодуля → локальная подготовка изображения → состояние ready`.

## Загрузка

Сохранена пятиэтапная заставка HOTFIX26:

- Интерфейс;
- База продуктов;
- Расчёты и инструменты;
- Проверка готовности;
- Готово.

Пройдены штатный, замедленный и два резервных сценария. Нормальный видимый цикл в автоматическом стенде составил около 4,2 секунды.

## Регрессия

- 108 проверок формул — успешно;
- 74 проверки нормативов — успешно;
- 1105 продуктов — успешно;
- runtime-замыкание: 297 файлов, отсутствующих файлов нет;
- 37 групп статического релизного аудита — успешно;
- 946 общих защищённых файлов относительно HOTFIX26 побайтово идентичны.

## Граница подтверждения

Приёмка выполнена в автоматизированном Chromium со смоделированными ответами браузерного API. Она подтверждает корректность программной реакции на успех, отказ и зависание. Фактическое системное окно разрешения на конкретном телефоне зависит от HTTPS, браузера, Android и настроек сайта.
