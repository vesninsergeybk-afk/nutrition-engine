# Ivory & Brass v6.0 alpha 1 — примечания к выпуску

Выпуск добавляет третью переключаемую тему и новую desktop-модель рабочего пространства, сохраняя последовательную мобильную архитектуру.

## Как открыть

1. Откройте «Настройки интерфейса» или переключатель «Тема».
2. Выберите **Ivory & Brass**.
3. На широком экране выберите **Полотно**.
4. На телефоне приложение автоматически оставит **Разделы**.

## Аварийное восстановление

При проблеме с новым интерфейсом добавьте к адресу:

`?safe-ui=1`

Приложение откроется в Modern без удаления профиля и рациона.

## Развёртывание

Приватный hosting-архив уже содержит текущие серверные ключи Gemini в защищённом PHP-файле. После распаковки удалите ZIP из публичного каталога. Проверьте один запрос с фотографией и один запрос голосом на HTTPS-хостинге.
