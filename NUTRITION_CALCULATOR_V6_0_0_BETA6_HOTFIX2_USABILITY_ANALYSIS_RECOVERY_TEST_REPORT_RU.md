## Браузерная методика и ограничение среды

Интерактивные сценарии проверены в Chromium на изолированном интеграционном DOM с реальными Hotfix 2 JS и CSS и моками публичных API приложения. Среда выполнения блокирует переход Chromium как к `http://127.0.0.1`, так и к локальному `file://` правилом администратора (`ERR_BLOCKED_BY_ADMINISTRATOR`), поэтому полное открытие всего 53-МБ серверного пакета непосредственно из этой среды невозможно.

Это ограничение не относится к коду пакета. После развёртывания обязательна короткая серверная приёмка, особенно реального запроса разрешения на микрофон, поскольку его итог зависит также от HTTPS, разрешений браузера и устройства.

## Защищённый контур

Файлы `api/gemini.php`, `api/gemini-guard.php`, `api/gemini-secret.php` и `api/utf8-safe.php` не изменялись. Расчётное ядро, продуктовые данные и нормативные файлы не изменялись.
