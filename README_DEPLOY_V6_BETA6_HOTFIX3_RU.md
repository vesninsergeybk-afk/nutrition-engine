# Развёртывание Beta 6 Hotfix 3

1. Создайте резервную копию текущей серверной папки Hotfix 2.
2. Распакуйте серверный архив Hotfix 3 в корень приложения с заменой файлов.
3. Убедитесь, что закрытый `api/gemini-secret.php` остался на сервере. В поставляемом приватном архиве файл сохранён без изменений.
4. Очистите серверный кэш, CDN-кэш и кэш браузера либо откройте страницу с новой версией параметра `v`.
5. В заголовке должна отображаться версия `v6.0.0-beta6-hotfix3`.
6. Проверьте на компьютере:
   - три темы;
   - «Разделы / Полотно»;
   - расчёт потребностей;
   - карту аналитики;
   - возврат из HEI и нутриентов.
7. Проверьте на телефоне по HTTPS:
   - «Записать голос»;
   - «Диктофон устройства»;
   - разрешение микрофона;
   - отсутствие горизонтальной прокрутки шапки.

При сомнении в кэше сравните `release-manifest.json` и убедитесь, что `release_version` равен `v6.0.0-beta6-hotfix3-quality-completion`.
