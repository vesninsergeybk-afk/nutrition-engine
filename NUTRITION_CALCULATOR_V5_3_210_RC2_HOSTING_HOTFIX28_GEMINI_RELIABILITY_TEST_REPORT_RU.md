# Отчёт о тестировании HOTFIX28

Версия: `v5.3.210-rc2-hf28-gemini-reliability`

## Итог

HOTFIX28 принят по повторному автоматизированному и аудиторскому проходу. Существующие основной и резервный ключи Gemini включены в оба приватных архива только в защищённом серверном `api/gemini-secret.php`. Клиентский код и HTTP-ответы значений ключей не содержат.

Ответ настоящего Gemini API в контейнере не получен из-за DNS-недоступности Google. Русскоязычный WAV с длинным контекстом прошёл согласие, загрузку встроенных ключей, проверку файла, UTF‑8-подготовку и дошёл до транспортного вызова. Полный успешный путь ответа отдельно проверен mock-провайдером.

## Специализированные проверки

- UTF‑8 без `mbstring`: **8/8**.
- Статический договор согласия и клиент-серверные поля: **13/13**.
- Mock end-to-end с настоящим русскоязычным WAV: **12/12**.
- Загрузка ключей из environment, внешнего и встроенного файла: **11/11**.
- HTTP-изоляция встроенного файла: **6/6**.
- Основной HTTP-контракт: **5/5**.
- Браузерные сценарии Chromium: **7/7**.
- Финальный аудиторский проход: **57/57**.
- Runtime closure: **300 файлов**, отсутствующих зависимостей нет.
- `api/gemini-secret.php` присутствует в hosting-архиве и полном приватном архиве.
- Основной и резервный ключи обнаруживаются только внутри защищённого серверного файла.
- Прямой HTTP-запрос к файлу возвращает 404 и пустое тело.

## Браузерные сценарии

1. Фотография подготавливается, не изменяя состояние микрофона.
2. Успешное разрешение микрофона включает видимое состояние записи.
3. Ложный отрицательный ответ `permissionsPolicy` не блокирует `getUserMedia`.
4. После отказа остаётся понятная кнопка повторной записи.
5. Зависшее разрешение завершается мягким предупреждением и тайм-аутом.
6. Повторное нажатие не создаёт второй запрос.
7. В небезопасном контексте доступен системный диктофон.

## Проверка встроенных ключей

Проверено без переменных окружения:

- health-ответ сообщает `configured: true`;
- загрузчик видит основной и резервный ключи;
- ключи различны и имеют корректные именованные слоты;
- значения не появляются в health-ответе;
- прямой запрос к `api/gemini-secret.php` получает HTTP 404;
- тело прямого ответа пустое;
- значения не обнаружены ни в одном другом файле проекта или архива;
- переменные окружения и `GEMINI_SECRET_FILE` по-прежнему могут переопределить встроенный комплект.

## Реальный транспортный проход

Через настоящий PHP endpoint отправлен русскоязычный WAV. Использовался встроенный серверный комплект ключей, без `GEMINI_API_KEY` и `GEMINI_SECRET_FILE`.

Результат:

- HTTP 503;
- `error_code: transport_error`;
- `request_count: 1`;
- ошибок `Malformed UTF-8`, `encode_error` и `php_fatal_error` нет;
- внешний ответ не подтверждён только из-за отсутствия DNS-доступа к Google API.

## Регрессии

Расчётное ядро, нормативы, HEI и база из 1105 продуктов не изменялись. Защищённые файлы сравнены с HOTFIX27. Новых отказов относительно HOTFIX27 не обнаружено.

## Проверка после загрузки на хостинг

На реальном HTTPS-домене остаётся выполнить:

1. голосовую запись на русском;
2. готовый аудиофайл;
3. фотографию продукта;
4. отказ в микрофоне и повторное разрешение;
5. Android Chrome и iPhone Safari.

После распаковки следует удалить приватный ZIP из публично доступного каталога. Ротация существующих ключей по причине их использования в приватных материалах проекта не требуется.
