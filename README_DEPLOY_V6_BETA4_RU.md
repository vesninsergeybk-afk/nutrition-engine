# Развёртывание V6 Beta 4 Profile Hierarchy

1. Создайте резервную копию текущего сайта и данных браузера, используемых для проверки.
2. Загрузите hosting-архив в закрытую или временную область хостинга.
3. Распакуйте его в каталог приложения с заменой файлов предыдущей Beta 3.
4. Убедитесь, что `api/gemini-secret.php` имеет серверные права `0600` или максимально близкие, разрешённые хостингом.
5. Удалите загруженный ZIP из публичного каталога после распаковки.
6. Откройте сайт с параметром `?safe-ui=1` для аварийной проверки Modern, затем без параметра.
7. Проверьте первый профиль, расчёт, перезагрузку, добавление продукта, сводную таблицу, HEI, Гарвардскую тарелку, отчёт, фотографию и голос.
8. При кэшировании CDN очистите HTML-кэш; CSS/JS имеют версионные URL Beta 4.

Существующие основной и резервный ключи Gemini уже входят в приватную серверную поставку и не должны переноситься в HTML или JavaScript.
