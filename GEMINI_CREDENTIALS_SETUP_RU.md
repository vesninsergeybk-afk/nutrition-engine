# Ключи Gemini в HOTFIX28

Приватные архивы HOTFIX28 уже содержат существующие основной и резервный ключи Gemini в серверном файле:

`api/gemini-secret.php`

После обычной распаковки на PHP-хостинге дополнительная настройка ключей не требуется. Приоритет — немедленная и надёжная работа распознавания фотографий, голосовых записей и аудиофайлов.

## Защита ключей

Ключи находятся только в PHP-файле на серверной стороне и не передаются в HTML, JavaScript, `localStorage`, health-ответы или пользовательские сообщения об ошибках.

Защита реализована в несколько уровней:

1. прямой запуск `api/gemini-secret.php` возвращает HTTP 404 и пустое тело;
2. корневая `.htaccess` запрещает прямой доступ к файлу;
3. дополнительная `api/.htaccess` повторяет запрет внутри каталога API;
4. файл упакован с режимом `0600` там, где распаковщик сохраняет Unix-права;
5. серверный endpoint сообщает только факт настройки Gemini, не раскрывая сами значения ключей.

После распаковки приватный ZIP-файл не следует оставлять в публично доступном каталоге сайта, поскольку сам архив содержит серверную конфигурацию.

## Дополнительные способы настройки

При необходимости встроенные ключи можно переопределить без изменения проекта:

- `GEMINI_API_KEY` — основной ключ;
- `GEMINI_API_KEY_BACKUP` — резервный ключ;
- `GEMINI_API_KEYS` — дополнительный пул ключей;
- `GEMINI_SECRET_FILE` — абсолютный путь к отдельному PHP-файлу.

Приоритет загрузки:

1. переменные окружения;
2. файл, указанный через `GEMINI_SECRET_FILE`;
3. встроенный защищённый `api/gemini-secret.php`.

## Проверка после установки

1. Откройте приложение на реальном HTTPS-домене.
2. Убедитесь, что health-запрос `api/gemini.php` сообщает `configured: true`.
3. Выполните короткую голосовую запись на русском языке.
4. Проверьте загрузку готового аудиофайла.
5. Проверьте фотографию одного продукта.
6. Удалите загруженный ZIP из публичного каталога после распаковки.

Перевыпуск или отзыв существующих ключей только из-за их передачи в приватных материалах проекта не требуется.
