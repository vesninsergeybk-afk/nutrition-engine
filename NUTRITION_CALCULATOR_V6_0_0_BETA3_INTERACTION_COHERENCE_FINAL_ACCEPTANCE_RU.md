# Итоговая приёмка V6 Beta 3

## Критерии выпуска

- единый контракт состояний работает во всех трёх темах;
- desktop и mobile сохраняют свои оптимальные модели компоновки;
- фокус, выбор, нажатие, загрузка, успех, ошибка, disabled и recording различимы;
- мобильные основные цели не меньше 44 px;
- профиль сохраняется и восстанавливается;
- сводная таблица, HEI, Гарвардская тарелка и отчёт не потеряны;
- обзор групп ведёт к канонической таблице;
- фото и микрофон не имеют регрессий;
- расчётное ядро не изменено;
- архивная поставка повторно проверяется после распаковки.

## Принято

Рабочее дерево прошло release audit 52/52, а специализированные браузерные наборы — 43/43. Runtime closure содержит 315 файлов без пропусков; 184 защищённых файла неизменны; база содержит 1105 продуктов.

Окончательный статус архивов и их SHA-256 фиксируется в машинном отчёте архивной проверки после повторного запуска тестов на распакованной серверной поставке.
