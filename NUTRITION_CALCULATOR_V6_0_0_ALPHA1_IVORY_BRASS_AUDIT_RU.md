# Аудиторский отчёт v6.0.0 alpha 1 «Ivory & Brass»

## Результат

Финальный автоматизированный аудит: **48/48**.

## Проверенная граница изменений

Новый слой отвечает только за тему, компоновку и проекции данных. Расчётные формулы, продуктовые данные, нормативы и серверный Gemini-контур не были переписаны.

`NutritionUIViewModel.v1` читает каноническое состояние и существующие результаты. До применения профиля нормативные цели в новой теме не публикуются, поэтому временные внутренние значения не выдаются пользователю за рассчитанные ориентиры.

## DOM и доступность

- формы не переносятся между родителями;
- профессиональные поля только скрываются и раскрываются на прежнем месте;
- логический порядок DOM сохранён;
- мобильный режим принудительно последовательный;
- программно сфокусированный заголовок остаётся доступным для объявления, но не получает рамку поля ввода;
- предусмотрены `aria-pressed`, `aria-expanded`, `aria-disabled`, `aria-busy`;
- состояние не передаётся только цветом;
- поддержан `prefers-reduced-motion`;
- печать использует упрощённую структуру.

## Безопасность Gemini

Согласно принятому для проекта решению, существующие основной и резервный ключи входят в приватную серверную сборку. Они находятся только в `api/gemini-secret.php`.

Проверено:

- файл присутствует;
- права в рабочем дереве и ZIP — `0600`;
- прямой HTTP-запрос возвращает 404 и пустое тело;
- ключи не обнаружены в HTML, JavaScript и HTTP-ответах;
- `.htaccess` блокирует прямую выдачу;
- переменные окружения и внешний файл остаются возможными переопределениями;
- health endpoint видит настройку, но не раскрывает значения.

После распаковки приватного архива загруженный ZIP следует удалить из публичного каталога сайта.

## Производительность

Ivory & Brass добавляет около 41 КБ CSS и 52 КБ JavaScript без сжатия. Тяжёлые framework-зависимости и растровые hero-изображения не добавлены: декоративная композиция, диаграммы и иконки построены SVG/CSS.

## Выявленные и устранённые дефекты аудита

1. Старый design-system CSS перекрашивал новые кнопки в синий из-за более высокой специфичности.
2. Dashboard показывал временную цель 2000 ккал до расчёта профиля.
3. Программный фокус на заголовке выглядел как активное поле.
4. При уходе с Ivory скрытые результаты поиска не восстанавливались немедленно.
5. Специальные поля были слишком заметны обычному мобильному пользователю.
6. В интерфейсе сохранялась внутренняя английская фраза `External-target-only`.

Все пункты исправлены и покрыты повторными тестами.

## Что ещё нельзя подтвердить внутри контейнера

- успешный живой ответ внешнего Gemini;
- системные диалоги разрешений на реальных мобильных устройствах;
- Safari/WebKit и Qt WebEngine на физических системах;
- результаты исследования с живыми обычными и профессиональными пользователями.

Поэтому статус выпуска — **alpha 1**, несмотря на полный автоматизированный аудит.
