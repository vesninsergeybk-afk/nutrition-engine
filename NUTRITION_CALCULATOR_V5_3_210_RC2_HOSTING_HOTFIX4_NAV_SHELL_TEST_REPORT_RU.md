# HOTFIX4 NAV SHELL — отчёт о тестировании

## Результат

Навигационная оболочка прошла внутреннюю техническую и UX-приёмку в Chromium. Действующий расчётный контур, HEI-2020 HF3, защищённые режимы, отчёты и длинное полотно сохранены.

## Специализированные проверки оболочки

- статический контракт навигации: **14 из 14**;
- браузерные сценарии оболочки: **5 из 5**;
- автоматизированный WCAG 2.2-аудит: **8 из 8 сценариев** — desktop/mobile × long/ration/HEI/correction;
- серьёзные и критические нарушения axe после исправления контраста: **0**.

Проверены:

- режим длинного полотна по умолчанию;
- включение и выключение нового режима;
- четыре основные рабочие области;
- три представления анализа;
- hash-маршруты и история браузера;
- сохранение введённого текста и состояния;
- скрытие неактивных секций без удаления из DOM;
- коррекционная проекция HEI без дублирования полной таблицы;
- одна нижняя мобильная навигация;
- отсутствие горизонтальной прокрутки при ширине 390 пикселей;
- обратимость раскрытия настроек;
- отказоустойчивость при запрете Web Storage.

## Регрессионные проверки

Браузерные сценарии существующего приложения:

- app smoke: **5 из 5**;
- профессиональный рабочий процесс: **2 из 2**;
- HEI HF3 UX: **1 из 1**;
- мобильная коррекция продуктов: **1 из 1**;
- общий browser release gate: **4 из 4**;
- формульные golden-сценарии: **3 из 3**.

Всего выполнено **29 браузерных сценариев**, включая специализированные проверки новой оболочки и регрессию существующего интерфейса.

Статические и расчётные проверки:

- полная статическая целостность: **2336 утверждений**;
- runtime consolidation: **56 утверждений**;
- HEI-2020 HF3: **51 утверждение**;
- профессиональный рабочий процесс: **13 утверждений**;
- навигационная оболочка: **14 утверждений**.

Дополнительно пройдены проверки DOM-состояния, CSRF, PHP-ограничителей, межпроцессной блокировки, политики хранения, версий, прав файлов и Apache staging.

## Проверка UX

На реальном сценарии с рассчитанными потребностями и добавленной котлетой по-киевски проверены desktop 1440×1000 и mobile 390×844.

Подтверждено:

- при переходе в режим разделов пользователь попадает к заголовку текущей рабочей области;
- на мобильном нет второго закреплённого слоя поверх нижней навигации;
- анализ не содержит блока ввода по фото/аудио;
- активный раздел и активное представление анализа различимы;
- вспомогательные настройки не занимают рабочую область постоянно;
- прежнее полотно возвращается без потери рациона и введённых данных.

## Ограничения проверки

- локально полноценно проверен Chromium;
- Firefox и WebKit должны пройти отдельный CI-прогон;
- автоматизированный axe-аудит не заменяет ручную проверку экранными дикторами на физических устройствах;
- оболочка пока включается пользователем и не является принудительной заменой существующего режима.
