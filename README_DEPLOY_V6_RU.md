# Развёртывание v6.0 alpha 1

1. Создайте резервную копию текущей HOTFIX28.
2. Распакуйте hosting-архив поверх отдельной тестовой директории или атомарно замените текущую публикацию.
3. Убедитесь, что `api/gemini-secret.php` имеет права `0600` или максимально строгие права, поддерживаемые хостингом.
4. Удалите загруженный ZIP из публично доступной директории.
5. Откройте `api/gemini.php?action=health`: должно быть `configured: true`, но ключей в ответе быть не должно.
6. Проверьте Modern, 2-bit и Ivory & Brass.
7. На desktop проверьте «Полотно», на телефоне — последовательные «Разделы».
8. Выполните живой тест фотографии и записи голоса.
9. При ошибке интерфейса используйте `?safe-ui=1`.

Расчётные данные пользователя в `localStorage` при штатном обновлении не удаляются.
