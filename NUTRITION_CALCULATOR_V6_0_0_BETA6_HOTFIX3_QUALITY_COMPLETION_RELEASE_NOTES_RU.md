# Beta 6 Hotfix 3 — примечания к релизу

Hotfix 3 завершает доработку пользовательских маршрутов Beta 6 после практического тестирования Hotfix 1 и Hotfix 2.

Главный результат — интерфейс больше не только содержит восстановленные функции, но и делает их предсказуемо доступными. Верхняя панель корректно работает во всех трёх темах; голосовой ввод явно предлагает браузерную и системную запись; обзор анализа сразу показывает матрицу, Гарвардскую тарелку и HEI; подробности имеют контекстный возврат.

Сборка не меняет формулы, продуктовые данные или Gemini-ключи. Она предназначена для загрузки поверх Hotfix 2 с полной заменой файлов и обязательной очисткой кэша.
